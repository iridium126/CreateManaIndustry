# 魔法工作站 Ponder：实现与游戏内验收

## 实现范围

30 段教程，147 段中英文正文；入口仍为 `CMIPonderPlugin`。每段使用独立的 `ponder/workshop/<id>.nbt`，铺设参考结构里的层叠方解石地板，并将樱花木装饰水平旋转后放在后沿。后沿花盆和紫晶芽上方设有不可见的 Ponder 灯光块，方块状态仍按参考结构保留。机器通过 Java 指令分步搭建，主要说明附带关键帧。

`Workshop` 负责场景内搭建、传动、液量、交互提示和雾效；`AssemblyWorkshop` 负责机械手、注液器、冲压机的传送带流程。物品加工结果使用实际物品和联动数据转移方法。Ponder 的雾元素独立于真实世界雾场及 Veil，每次回放重新创建。

分类包括魔法工作站、体积雾场、魔法自动化，并关联 Create 的动力、流体、动力臂和显示链接器分类。可选场景在模组和必要注册项存在时才注册，齿轮链场景同时要求 Trickster 和 Bits ’n’ Bobs。

未修改配方、机器规则、配置平衡或网络协议。

移动储罐并入储罐教程，动力臂搬运晶结并入充能教程，反转与装壳并入魔力齿轮教程；不再重教通用机器的完整配置。每段保留 4～7 条正文。多幕场景切换时清理工作区，保留地板和背景。

中文以 `.refs/Create` 的简体中文本地化为基准，统一使用动力臂、石磨、显示链接器、边框玻璃活板门、动态结构和右击。正文使用简短的功能及操作说明，不添加句末句号、感叹号或分号；只有“为悦灵安个家”和“机器旁的音乐角”按用户要求保留原题。联动模组和本模组独有的物品名称保持不变。

正文逐条安排 60～120 tick 的稳定显示时间，Ponder 另加共 10 tick 的淡入淡出。`text` 用于静态说明；`explain` 提前 20 tick 显示说明并附加关键帧，让后续动作与字幕重叠。下一条正文、工作区清理和结束都会等待当前字幕与操作提示结束，连续操作提示也包含淡入淡出的等待，避免叠字、提示重叠或指向已经移除的机器。所有等待经 `Workshop.idle` 计入时间轴，结尾只保留 20 tick，不再按正文条数补足固定总时长。

首次放置使用 `Workshop.place` 播放入场动画；已显示方块的装拆壳及燃烧室更换使用 `replace` 原位更新，保留虚拟方块实体标记，不再生成新的入场动画。活板门首次放置使用 `ProcessingPonderScenes.lid`，随后开合只修改 `OPEN` 状态。冲压装置的方块朝向与实际输入轴一致：工作盆装置使用 X 轴，组装流水线使用 Z 轴。

流水线和冷凝回路按 Create 的结构场景成组出现，媒质之瓶首条正文的脚本出现时间由约 13.2 秒缩短为 2 秒。机械手伸出、收回各 25 tick，动力臂按本体示例使用 48 RPM，取料、送料各 24 tick，中间停留 20 tick；储罐旋转一圈为 70 tick。32 RPM 的冲压演示等待 65 tick，使压头完全返回后再换物品或放行。搅拌演示显式设定下降、搅拌、抬起三个阶段，并在结束后复位，不继承上一遍的加工计时。这些都是教程内动画，不改变真实机器的速度或配方。

新增 `allay_heat_levels`，按普通加热 → 超级加热 → 悦灵加热讲解递进关系。燃烧中的悦灵燃烧室覆盖前两档要求；超级加热的烈焰人燃烧室无法满足悦灵加热配方。燃烧室本身只有空置、装入悦灵但没有燃料、悦灵加热三种状态；无燃料时无法提供加工热量，固态和液态燃料提供同档热量，追加燃料延长时间。燃料演示使用 120 tick 正文与两个完整错开的 40 tick 右击提示。汽化对照保持活板门打开，最后原位更换燃烧室。

新增 `water_mist_irrigation`，仅从动力雾化器进入，排列在范围教程之后。六条中英字幕参考 Create 动力泵与动力犁教程的短句风格，均不加句末句号。开场只显示耕地与小麦，第一条说明出现后，左侧雾化器及供水、传动装置逐个入场，连接完成后产生水雾。右侧近、远两组耕地先后湿润；部分种植固定生长阶段的小麦，留出裸露耕地观察颜色。32 RPM 时近处满足浓度大于 10% 的条件，提速至 96 RPM 后远处也满足条件。停转后先等待雾效消散，再分步降低耕地湿度，干燥时间按教程节奏压缩，不演示液体雾重叠、不改变作物生长阶段或真实世界规则。字幕源与翻译使用 `10%%`，经格式化后显示 `10%`；正文显式使用格式化接口，使正常播放和 Ponder 编辑模式的结果一致。

## 已执行验证

- `python scripts/ponder/resources.py --check`：检查场景 ID、故事板方法、NBT 内容及目录无残留结构、双语标题及正文顺序、两处保留标题、中文术语和标点、字幕时长范围、可选依赖条件，以及教学示例对应的配方用量和热量条件。
- `gradlew.bat compileJava processResources --offline --console=plain`：Java 编译与资源处理。
- `gradlew.bat test --tests "*PonderSceneContractTest" --offline --console=plain`：双语正文格式化、百分号结果、编辑模式格式化接口、原位替换与活板门状态修改的回归检查。
- `git diff --check`：补丁空白检查。

这些检查不能证明场景的运行时视觉效果、缺少联动时的类加载行为或装置可实际运行。按用户安排，以下游戏内验收交由用户执行。此前本地开发客户端尝试在 Sodium 加载阶段失败，未进入场景；临时探针与启动配置已移除。

## 每段共同验收

1. 正常播放一遍；确认方块、物品、液面、旋转、机器动作和产物都出现，且说明指向正确位置。
2. 每个关键帧暂停，再前进和后退；最后从头重播两次。检查物品没有重复、雾范围没有继承上一遍、机器没有卡在加工中途。
3. 在雾出现、动力臂移动、唱片插入三个阶段分别退出。确认主世界无新增雾源或遗留声音。
4. 简体中文和英文各检查一次；GUI 缩放 2、3、4 或窗口允许的最大值。检查文字是否覆盖主要连接、机器是否被裁切、半透明雾是否遮住液面。
5. 检查分类索引能找到入口；八种冷凝管和八种镀层板各抽查入口，未完成晶结与施法物品共享对应流程。
6. 热量教程逐幕跳转和重播：前幕搅拌器、冲压机、物料和液体不残留；超级加热烈焰人对照中液量保持 125 mB 且无雾；换回悦灵燃烧室后液量归零并产雾。
7. 分别关闭、开启舒适阅读模式验收字幕与动作的同步。重点观察动力臂取放、冲压机抬头后放行、搅拌器抬起、32→16 参数变化及缺少玻璃的失败对照；应能在同一条字幕期间看清动作，两个对照状态之间有完整阅读时间。
8. 水雾灌溉教程由用户执行客户端验收：在简体中文、英文及不同 GUI 缩放下检查近处先湿润、远处在提速后湿润、停转消雾后恢复干燥；字幕不遮挡农田，指向与颜色对照正确。逐关键帧前进、后退并连续重播两次，确认湿度、液量、转速、雾范围均复位，小麦不提前成熟；在雾出现时退出，主世界无遗留雾效。
9. 本轮修复由用户检查：魔力齿轮装壳、拆壳及燃烧室更换时没有第二个模型入场；灌溉场景开场只有农田，机器随后逐个出现；热量等级的固态与液态燃料提示完全错开。两种语言在正常播放与编辑模式下均显示单个 `10%`，没有格式错误；分类名称显示“体积雾场”。抽查所有工作盆及流水线冲压机的传动轴，汽化活板门打开、沉积时关闭；检查显示链接器的 32、16 数量提示与库存变化一致，再进行关键帧前后跳转和重播。

唱片场景设置唱片物品状态，不启动世界级唱片音频。雾的显示半径与液量变化按教学节奏编排，不是生产速率基准。配置相关产量与速率以服务器实际配置为准。

## 可选依赖组合

分别在基础依赖、增加 Trickster、增加 Trickster＋Bits ’n’ Bobs、增加 Hexcasting、全部安装的环境中打开 Ponder。基础环境应只有 23 段本模组教程；Trickster 增加 3 段，齿轮链额外增加 1 段，Hexcasting 增加 3 段，全部安装共 30 段。其他模组自带教程不计入此数量。缺少可选模组时，不应出现对应入口或类加载异常。

## 实际世界复现

- 燃烧室供热冲压紫水晶、动力臂自动添料、泵供媒质。
- 验证悦灵加热兼容普通加热与超级加热；在活板门打开的工作盆中汽化时，超级加热烈焰人燃烧室失败、燃烧中的悦灵燃烧室成功。
- 冷却液沿冷凝管贯通，下方分液池回收灵魂液；装满或移除分液池后停止回收。
- 关闭边框玻璃活板门，在媒质雾中沉积铁板；玫瑰石英镀层另需热源。
- 魔力雾驱动齿轮与石磨，换媒质雾验证反转。
- 向动力雾化器供水并输入旋转动力，在无附近水源时验证浓度大于 10% 的耕地湿润，提速可覆盖更远处耕地，停转失去水雾后恢复干燥。
- 绿宝石＋玻璃部署、重复注魔、获得完整晶结；冲压验证开裂。
- Hexcasting 写入图案、注液、冲压，比较前后数据；媒质之瓶取液后再灌注。

记录问题时附上场景 ID、语言、GUI 缩放、模组组合、配置是否修改、具体关键帧以及实际观察，便于复现。

## 后续维护

编辑 Java 场景中的英文及中文字符串，然后运行 `python scripts/ponder/resources.py --write`，再运行 `--check`。字幕调用首参数是以 tick 为单位的稳定显示时长；新增操作说明优先使用 `explain`，在必要的结果观察点调用 `waitForText`，所有动作等待使用 `w.idle`。删除场景时同步移除对应 NBT，脚本会拒绝残留结构。不要单独手改生成的 Ponder 翻译或 NBT。脚本不需要第三方 Python 包。配方校验失败时先核实教学步骤是否需要同步更新，不能仅放宽断言。

正文不接受格式参数，字面百分号需写为 `%%`，资源校验会拒绝未转义的百分号。操作提示统一经 `Workshop.controls` 或 `use` 创建，保持结束时间可追踪；不要在故事板中直接调用 `showControls`。已显示方块改外观用 `replace`，同一活板门开合用 `setLidOpen`，不要重复调用首次放置方法。

参考源码来自 `.refs/Create` 的机器动作与流体场景、`.refs/CreateEnchantmentIndustry` 的工坊编排，以及 `.refs/Ponder` 的指令、场景边界和回放生命周期。
