# Allay Storm：单柱星雨、天穹与双螺旋

当前核心协议 **9**。风暴仍为独立身份／生命状态的GPU MODEL群体，服务端拥有持久化、成员HP／死亡、攻击计划和最终伤害结算，不创建大量成员实体或新增服务端成员位置模拟。

## Starfall 单柱星雨

Starfall已替换旧的追踪式多柱波次：每名位于风暴半径内的合格玩家，默认每0.5秒独立50%概率生成一柱；每柱64名，最多64柱。落点冻结在触发时玩家XZ，间距至少8格，拥挤时向外／两侧寻找，柱中心不超出风暴半径。

在主体下方8格环绕集合，完成后保持绕柱下降；每名成员独立确认触地后立即持钻石剑沿自己的方向展开，随后收剑归队。只有绽开有区域接触伤害；半径最大4格，高度遵循 `h = 0.0625r²`，外缘高1格。64个方向与触地点分散，使用稳定飞行姿态和连续渲染时间；下降／展开／回流按三维弧长6格／秒推进，成员逐个立即换阶段，允许碰撞偏离参考面或降低实际速度；不等待整柱。地面128粒子预警圈半径4格，单粒子尺寸为旧版一半。

完整参数、调度／地形边界、协议、性能解释和用户实机清单见 [单柱星雨](starfall-columns.md)。

## 天穹与双螺旋

星雨独立调度，不占大招4槽或原冷却。每名玩家默认每60秒一次大招机会：20%天穹、20%双螺旋，其余60%安静；不再回退至旧追踪式Starfall。每目标最多一个大招，全部攻击共享成员预留。

天穹按20%存活成员选员，默认上限16384，至少768名；锁定后为区域攻击，不因原目标离开消失。只定位一次中心地面，起伏、障碍不再中止整波；六瓣与顶冠自身作为预警。规则见 [天穹合围](gpu-dome-2026-10-11.md)。

双螺旋按10%存活成员选员，默认上限8192，从相对的两条臂选员，至少512名且相对两臂各至少256名。直接在玩家后方24格、上方24格附近集结，每10 tick跟随更新；完成立即冻结45°向下轴线并突刺。长度32–64格、半径3–6格，局部法平面高斯散布σ=0.2R、径向截断3σ，随机偏移按成员身份缓存。保留原突刺速度配置和区域扫掠接触。规则见 [双螺旋贯击](gpu-helix-2026-10-11.md)。

## 战斗、同步与验收

星柱、天穹和双螺旋的成员名单互斥；结束／中止释放预留。波次途中死亡不补员。健康成员默认20HP，既有回血、受击、尸体和永久死亡语义不变。

近战候选由客户端GPU提供，服务端计算武器、附魔、冷却、暴击和击退。区域接触由各玩家客户端报告自身候选，服务端保留身份、名单、存活、有限数及去重，信任客户端实际阶段候选，再按原版伤害流程结算。近战使用递增attackSeq、每tick一次／20tick最多12次，服务端复用Allay代理；本地预测挥手不发送原版挥手包。默认接触伤害7点，盾牌、护甲、吸收、图腾及无敌帧继续生效。

协议见 [同步协议](allay-storm-sync.md)。此前生命周期／近战／持久化／波次槽审查修复及原点漂移修复保留在 [修复记录](allay-storm-review-fixes.md)。历史星冠实现和基准见 [开发记录](gpu-starfall-2026-10-11.md)，该记录中的旧队形和配置不代表当前Starfall。

自动化验证不代替客户端实机；双客户端、真实地形、光影包、视觉规模和多人帧率由用户验收。
