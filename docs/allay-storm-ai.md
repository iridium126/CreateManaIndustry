# Allay Storm：星冠、天穹与双螺旋贯击

状态：🟡 星冠与天穹共用精确选员、当前帧 MODEL/持剑阴影及成员生命行为；星冠保留 128 粒子预警，天穹由六瓣群体自身预警。实机视觉、地形和战斗平衡由用户验收。

## 调度与天穹合围

每次攻击机会默认独立抽签 20% 天穹 / 20% 双螺旋 / 60% 星冠，允许连续同种；共享冷却、四波次、每目标一个波次与成员预留。天穹名单不足 768 或地形不适合时回退星冠。天穹规则、三个配置、协议 3、区域伤害及验证记录见 [天穹合围](gpu-dome-2026-10-11.md)。锁定后的天穹不因原目标离开而消失，区域内所有玩家都可被正在收拢的成员接触。

双螺旋按 10% 存活成员、默认上限 8192，从两条真实相对臂选员；冻结弯曲路线，仅贯击阶段采用默认 12 格/秒成员上限和区域扫掠接触。规则、协议 4 与证据见 [双螺旋贯击](gpu-helix-2026-10-11.md)。

## 星冠成员与规模

风暴仍是独立身份/生命状态的 GPU MODEL 群体，不生成大量 Minecraft 实体。成长、HP、回血、受击、尸体、永久生命周期及已死亡身份不再生成的语义保持原有行为。

| 服务端配置 | 默认 | 范围 |
| --- | ---: | ---: |
| `stormStarfallMembersPerColumnStep` | 4096 | 1–131072 |
| `stormStarfallMaxColumns` | 16 | 1–32 |
| `stormStarfallMembersPerColumn` | 512 | 1–4096 |

柱数为 `min(maxColumns, max(1, alive / step))`（整数除法，零存活时不发动）；4096 人一柱、8192 人两柱、65536 人十六柱。每柱精确选择 512 名可用成员，默认满规模每波 8192 人。存活成员不足或已被其他波次预留时减少实际规模，最后一柱可不足额。波次途中死亡不补员。

服务端使用有限全周期排列一次选员，发送明确名单及顺序。最多四个并行波次、每目标一个波次，同一身份不会同时属于两个波次；结束/中止释放预留。旧 `stormWaveFraction`、`stormWaveMaxSize` 已移除，新配置使用上表默认值；攻击间隔、伤害、范围和追击高度保留原配置。

## 星冠攻击阶段

1. 星团从主体升起组成倾斜 15° 的星冠，中心在发射时风暴中心上方 8 格。冠环半径至少为风暴半径的 70%，且相邻星团间距至少 4 格。集合时长随距离增长，速度仍封顶 6 格/秒。
2. 沿共享的最多六点 corridor 接近玩家上方约 10 格；锁定前每 0.5 秒更新目标，偏离超过 8 格时最多每 2 秒重建一次路线。目标失去开放天空资格时中止。
3. 服务端锁定落点：第一柱中心，其余黄金角错落分布，半径 `1.8*sqrt(column)`。检测地形和下降通道，不安全的外围点回退到安全中心，中心不安全则中止。
4. 至少预警 1 秒后，星柱以 0.35 秒间隔下降；以悦灵本体构成多股窄螺旋，身体和手持物使用共同姿态。锁定后不追踪逃离玩家。
5. 下降结束后分瓣展开 1.5 秒，再沿现有碰撞/避障与软回流归队。展开、回流和中止后的移动无伤害；不瞬移，不生成装饰性 MODEL 替身。

路径与实际群体物理均保留速度上限和碰撞。集结/接近/归队时长随路径与风暴尺寸变化；长期追踪波次有 180 秒最终截止。屋顶、动态障碍、狭窄/高差地形仍需实机对照。

## 圆环预警

每个落点恰好 128 个六边形 GPU 粒子，等角圆周排列；圆环半径为螺旋截面半径 1.2 格加接触半径 1.6 格，即 2.8 格。粒子中心固定在地面上方 0.20 格，采用相机朝向 billboard 和固定随机 roll。

共享 Hex conjure 的 `hexCloudShape` 柔边形状。原版初始 `quadSize` 是半边长 0.09–0.18 格，所以本提示完整 quad 边长为 0.18–0.36 格，保留尺寸分布；不使用原 conjure 的漂浮、重力、阻力、速度、指数缩小或生命周期。

使用悦灵蓝/浅青、稳定圆周明暗层次和低幅呼吸，预计首次接触前最后 0.7 秒提亮。中心、半径和单粒子尺寸不变；下降结束或中止后 0.25 秒淡出。启用深度测试、不写深度、不穿透地形、不投影。波次/风暴代标识不同的旧圆环不会重新绑定新攻击。

使用普通 ADDITIVE 池、每柱一次发射和 GPU 整组预约；容量不足时整组跳过；keygen 在主视锥剔除前统计当帧完整性，即使包裹容量预约挤掉普通记录，少于 128 个有效提示的圆环也整柱隐藏并禁用其伤害。没有新增粒子材质、绘制调用或逐帧粒子补发，不依赖 Hex 图案接管配置或 Hexcasting 安装状态，遵守粒子总开关。

## 接触与权威

GPU 从同代 STORM 活动索引检测，仅本地目标所属波次、下降阶段和当前 wave ID 的成员状态允许报告。报告使用绝对位置、采样时间与风暴代标识；服务端通过精确名单、阶段、通道和近两秒玩家位置历史验证，再去重并执行原有伤害类型。盾牌、护甲、吸收、图腾和原版无敌帧继续生效。

阶段状态按稳定身份保存，并随模拟 bank 提交，替换永久完成位。死亡成员不参与攻击，新波次允许同一存活成员重新参战。当前帧主画面和独立阴影读取同一提交；保持主画面排序与阴影列表分离。
