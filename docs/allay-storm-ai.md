# Allay Storm：当前行为与配置

核心协议 **18**，Dome模板 **v4**、Helix模板 **v1**。真实客户端验收由用户执行。[同步契约](allay-storm-sync.md)记录身份与数据所有权，[验证说明](allay-storm-validation.md)记录运行入口与验收边界。行为以当前源码为准，不按协议版本维护重复说明。

## 主体与调度

GPU MODEL群体保留稳定成员身份，服务端管理增长、HP、永久死亡和攻击名单，不创建逐成员实体或模拟成员位置。健康成员默认20HP。普通成员始终保留当前主体盘旋目标，攻击只覆盖参战成员导航，结束后继承实际位置与速度普通归队。

主体保留拖曳螺旋、原旋转速率及种子手性，旋转相位积分与瞬时角速度方向一致。中心追踪2格／秒，普通巡航和归队上限6格／秒，不另设高速追赶。仅三维距中心严格小于`0.2R`的成员可按原36秒周期跳舞；原生MODEL、阴影及Iris共用判定，姿态不改变运动。

三种攻击独立抽签、共享成员预留；Helix／Dome共享4个大招槽，Starfall独立64槽。同一成员不能同时参战，死亡不补员。人数、容量或资源不足消耗机会，不排队补发或降级。多人和同tick竞争轮换处理。

| 攻击 | 调度默认值 | 固定人数与条件 | 集结与攻击 |
| --- | --- | --- | --- |
| Starfall | 每名合格玩家每0.5秒独立50% | 每柱64名存活、未预留成员；最多64柱 | 主体下8格绕柱集结，逐成员下降、触地展开，0.5秒短回流后普通归队 |
| Helix | 每场风暴每30秒独立50% | 存活至少16384；对向两臂各2048名可用，共4096名 | 主体外缘下8格集结，追踪朝向；100%→90%动态门槛就绪即冻结已确认路线发射，逐成员穿出结束平面后普通归队 |
| Dome | 每场风暴每30秒独立50% | 存活至少16384；12288名可用成员 | 冻结玩家身体中心，汇入16–32格上半球流线；100%→90%动态门槛就绪后十二重星幕交错贯心，穿出3格后普通归队 |

Helix／Dome首次机会在激活30秒后，时钟使用各自配置。每次机会共享采集活动、同维度、存活、非旁观、范围及露天资格，概率先于昂贵选员和几何生成。两者均要求连续3个模拟帧距集合参考点≤0.4格、相对速度误差≤1格／秒；Helix／Dome均使用下述100%→90%动态门槛，分母须大于零。两者只将死亡／已确认退出的成员移出分母；未知覆盖、排队和搜索未完成不得冒充受阻退出。Helix集结不主动避障，已知受阻和未知覆盖不得缩小分母。仅就绪者参战，其余释放归队；截止仍不满足则中止。Dome受地形影响的流线本轮固定相位，但逐成员决定退出，不整条流线剔除；暂停后使用零参考速度判定就绪，截止时间不延长。

## Starfall：独立环绕星柱

触发者XZ、主体边界与集合高度在生成时冻结。柱中心最小间距8格；拥挤时从离主体向外的方向开始，在1格至风暴直径的整数环上按 `0,+15,-15,…,180°` 搜索，中心处方向由种子决定。最终网络坐标也参与间距校验。柱中心留在冻结风暴半径内，星花可越界4格。预约保留至绽开结束，短回流仍占成员与柱槽。

只定位落点中心地面，要求非流体支撑、集合平面高于地面；不扫描整片平整度或周期复查。允许坡地、台阶与动态障碍，实际移动由客户端碰撞裁剪、滑动及脱嵌处理。触发者离开、死亡或换维度不取消已生成区域攻击。

- 集结：四股各16名，轨道半径0.9–1.2格、纵向间隔0.7格；绕柱水平切向参考速度3格／秒，角速度 `ω=3/r`，位置与前馈速度共享相位。截获上限8格／秒，保留原保守集结时间。
- 下降：首次正常初始化时，距集合参考点≤0.4格且相对轨道速度误差≤1格／秒的成员使用水平切向3、向下`√27≈5.20`格／秒的初始切线，合速度6；向下分量立即加入，不保证完整速度向量连续。未就位或碰撞偏离者仍从实际位置和原入射方向初始化。快照恢复直接使用保存的曲线初值，不重新匹配。下降保持原三维弧长6格／秒，不要求整个下降段水平恒速3；没有新增入口阶段、0.25秒衔接或时序延迟。逐成员确认触地后立即展开，碰撞数据未知时继续无伤害运动，不悬停等待。
- 展开：64个独立方向，三维弧长6格／秒，参考面 `h=0.0625r²`，半径最大4格、外缘高1格。仅确认触地后的展开持钻石剑并允许接触，同帧跨阶段传递剩余时间。
- 短回流：立即关闭伤害、收剑，连续转向当前主体，目标速度6格／秒；0.5秒后释放并交给普通归队，不等待到达主体。碰撞允许实际降速和偏离参考曲面。

地面上0.20格的4格空心预警圈由128个柔边六边形粒子构成，单粒子完整边长约0.09–0.18格。集合浅青低亮，近地提亮、触地青白脉冲，结束／中止后0.25秒淡出；粒子不足不阻止有效伤害。触地声按柱合并，每客户端每tick最多2声。

## Helix：双股对数星锥

长64格、尾部外包络32格，双股各2048点、0.75圈确定性模板按局部高斯密度布置，初始中心间距至少1.4格。头部尖密、尾部宽散，不逐帧重新随机。离线排布仅在单个同股点冲突时以5%概率替换，最多800万次尝试；失败不写资源，运行时不排布。锚点为生成时主体外缘下8格，之后随主体平移；集结上限12格／秒、加速度18格／秒²、转向180°／秒，朝向每5tick更新，最大转速8°／秒。服务端发布带版本的连续刚体参考段，中心按端点速度的Hermite积分、姿态按旋转向量积分生成连续四元数，成员参考速度为中心速度加角速度叉乘相对位置。默认延迟0.25秒采样；缺包最多外推0.25秒并平滑停止；恢复时用0.25秒刚体Hermite修正连续接回，修正期间不授予就绪，重复快照不重启。位置和速度共用采样，空中集结不运行短射线避障，真实地形碰撞、滑动和脱嵌仍保留。服务端固定START预算计入调速、转向和反馈余量，不途中延长。就绪反馈携带参考版本和攻击内采样时间，服务端保留2秒历史、拒绝超过1秒的采样，并冻结被确认的轴线、基向量与中心；LOCK不再次瞄准。客户端以实际位置和速度进行0.5秒连续交接。

轴向参考速度固定12格／秒，不再读取速度配置；沿用0.15秒推进起步。绕轴相位`φ=−2π×0.75×progress/64`，位置和解析前馈共享冻结基向量，稳定角速度50.625°／秒。32格外包络理想合速度约30.72格／秒，实际合速度上限32格／秒。正常完成仍由碰撞后实际越过终止平面判定；参考旋进不能提前完成。逐成员退出立即收剑、关闭接触并普通归队，不再专用长回流。

## Dome：错落星流与交错贯心

开始选员／预留前，服务端检查冻结目标的32格上半球是否与当前主体包络重叠；重叠则尝试本次机会的其他合格目标，无目标可用时消耗本次机会，等待正常调度，不移动攻击中心或排队补发。直接启动入口也重复守卫，拒绝时不占槽、不取攻击ID、不预留成员。主体包络为覆盖所有旋转相位的圆柱：水平`1.15R+0.4`，竖直来自循环高度、`clamp(0.4R,3,8)`带厚与微扰；再计入两侧身体代理。检查上半球而非完整球，主体完全位于其下方时不误拒绝。诊断计数为`BODY_OVERLAP`。这是START前保守几何检查，不扫描服务端地形，不读取／上传GPU位置，也不承诺阻止启动后主体移动或增长造成的相交。身体碰撞和三帧运动就绪仍保留，Helix／Starfall不受该检查影响。

START固定集结预算，不途中重算或延长。`L=主体到冻结目标距离+1.15×主体半径+32`，时长为`ceil20(max(8,L/8+32/(8−6)+2×8/18+π/min(π,18/8)+0.75+1))`秒，其中`ceil20`向上取整至0.05秒。依次预算飞行、移动流线追赶、调速、转向、最大0.25秒步长的三帧和反馈。例：高差40、半径16时31.35秒；预算不是必须等待的展示时间。

总时长D tick，已过e tick限制在0～D；非空有效名单满足`10D×就绪人数 ≥ (10D−e)×有效人数`立即启动。门槛从100%线性降至90%，中点95%；12288名对应12288／11674／11060名。截止tick仍接收，下一tick中止；只冻结当次连续三帧合格者，未就绪者释放归队。实际身体碰撞仍保留，但身体重叠本身不直接清零就绪。

66条确定性三维闭合流线覆盖16–32格厚壳及顶部，同流线等弧长、同速，不同流线4–6格／秒，扰动总幅度≤0.6格。仅集结截获上限为8格／秒，截获预测、接触求解和最终运动裁剪使用相同上限，不按距离动态提速；加速度18格／秒²、转向180°／秒；Dome就绪在最终身体接触后按实际位置／速度判定，重叠或邻域扫描达到访问上限不直接否决，接触修正后仍合格可就绪。不永久累计，失配清零；未知覆盖、资源未就绪、目标被地形占用、死亡与退出均不能就绪，冻结相位变化重新计数。截获／近端跟随在距离`1～max(2,1+|v−v_ref|²/36)`区间平滑混合，提前减速和匹配方向。集结截获后共用身体包络直达检查、GPU局部路径和轻量避障回退；受阻窗口忽略脱嵌假进度，不因单帧滑动清零。流线冻结时不直接清零实际速度。LOCK按流线实际暂停相位循环映射通道，捕获当前相位与实际状态，连续接入攻击，沿用0.5秒交接至6格／秒，允许原8→6范围而非最终硬截。经历过集结的客户端使用本地连续交接时钟，重复快照不重启。

集结误差大于0.4格、累计已知地形阻挡至少0.1秒时，请求限预算GPU局部寻路。前向身体通道被已知地形截断也计入证据，不能因为短射线避障暂时选中了侧向／上方就永不请求。每成员最多一个在途请求，两次请求至少相隔0.5秒。搜索使用1格分辨率的8×8×8六邻接网格；窗口内接近真实集合点，否则寻找向集合点推进至少1格且后续2格通道已知畅通的出口。缓存最多8个转折点，使用不超过1秒；可直达集合方向时交还原截获器，转角提前制动，实际运动仍遵守8／18／180上限。

冻结后集合目标持续被已知地形占用0.5秒，该成员无伤害退出。其余成员必须已有完整、有效的“局部无路”结果，并且0.5秒窗口内已知地形阻挡至少0.1秒、集合误差减少不足0.05格，才可退出。未知覆盖、脱嵌、身份或阶段变化清空观察历史；排队、预算不足、路径转折点容量不足不等于无路，局部无路也不宣称全局不可达。退出当帧清除就绪／分母资格、剑和接触，提交完成位，随后普通归队且不重新加入本轮。归队者与仍集结者不再共享0.5格就绪接触类别，真实0.34格身体碰撞保留。超过局部搜索能力或原截止仍允许安全中止，不保证任意地形发动。

12组各1024通道，每组64条贯心、960条外围。贯心通道最近水平距离≤1格，外围覆盖1–8格，越过近心区继续穿出3格才结束；少量通道允许低于中心平面。异常成员在攻击阶段进入冻结中心的32格球体后，再次越界即无伤害退出；参考路线已耗尽且位于球外者，即使没有中心经过标记也退出。边界按成员身体中心的三维距离计算，集结与首次外缘汇入不受影响。退出当帧收剑、关闭接触、提交完成并接入既有普通归队。最长60秒故障回收。基础C2曲线、逆弧长表和同次攻击内部时空分离离线生成；正常向心不运行普通boids或多轮位置推挤。异常与跨攻击只进行一次预测接触／有界速度裁剪，持续地形受阻0.5秒无伤害退出。

Dome释放后立即关闭攻击，恢复覆盖前保存的普通盘旋目标、前馈速度和普通速度上限。首次退出最多用0.5秒五次平滑权重接入普通速度控制，之后使用普通分离、共享局部导航与地形碰撞；不新增专用回流路线。新攻击接管即取消旧交接。姿态缓存只影响显示，不能选择物理控制器，已结束成员不再采样仍有效槽位的攻击轨迹或执行其阻塞计时。

跟随状态采用0.04／0.10格滞回。共享GPU姿态缓存使用0.12秒响应、180°／秒转向上限；低速／近竖直保持有效方向，MODEL、阴影和Iris一致。手臂平滑不延长剑或伤害资格。资源证书仅覆盖编码基础曲线与闭合流线，不代替动态地形和任意交接下的实机验收。

## 共享GPU导航与排队回退

Dome集结和三种攻击结束后的普通归队使用同一套稳定成员身份导航。Starfall集结／下降／0.5秒短回流保持原时序，普通巡航不申请寻路。Helix集结移除主动转向避障，保持原始编队前馈，避免空地也出现稳定追赶误差。

直达身体通道畅通时直接跟随；否则优先接入有效局部路径，无路径或仍在排队／搜索／冷却时使用轻量回退。身体通道最多探测2格，前向受阻时检查上下45°、左右45°及左右90°六个候选，综合净空、推进方向和上一方向评分，以稳定身份破除平分。方向选择最多每0.1秒重算，缓存方向每帧复查；速度按18格／秒²制动距离和阶段上限裁剪。只有已知安全候选才继续绕行，封闭或未知时制动。回退不覆盖集合参考、不取消排队身份、不因侧滑清空原方向阻挡证据。

搜索仍为1格分辨率8×8×8六邻接、最多8个转折点、1秒缓存；误差大于0.4格且已知受阻至少0.1秒后请求，每成员一个在途请求、至少间隔0.5秒。总计128任务、每帧最多8192节点，Dome／归队竞争时保留96／32任务，空闲额度可借用。搜索开始时冻结起点，结果按成员实际位置重新验证接入；离开窗口或接入失败时丢弃并重试，不从旧起点施加位移。归队目标移动超过2格后重新申请。

Dome保留流线暂停和严格退出条件，排队、资源不足、路径容量不足和回退失败不等于无路。归队局部无路继续按冷却重试，不删除成员或伪造完成。新攻击、死亡、归队确认及风暴身份变化清理旧任务；候选历史随GPU双bank提交／回滚，最后一个Dome结束后归队仍可寻路，不依赖Dome曲线资源。状态显示队列、节点、回退人数、接入失败、最长等待及在途任务。不新增逐成员位置／路径上传。

## 配置与命令

服务端 `config/createmanaindustry-server.toml` 的 `allay_storm` 节，定义入口为 `infrastructure/config/ServerConfig.java`。

| 配置 | 默认值 | 范围 |

| `stormMaxCount` | 65536 | 1–131072 |
| `stormGrowthPerSecond` | 20 | 0–2048；0关闭增长 |
| `stormCorrectionHz` | 5 | 0.5–20 |
| `stormHelixInterval`／`stormDomeInterval` | 各30秒 | 5–600 |
| `stormHelixChance`／`stormDomeChance` | 各0.5 | 0–1；0关闭对应攻击 |
| `stormStarfallInterval` | 0.5秒 | 0.05–60 |
| `stormStarfallChance` | 0.5 | 0–1 |

| `stormWaveRange` | 96格 | 16–120 |
| `stormChaseY` | 128 | 40–300 |

旧共用 `stormWaveInterval`、`stormHelixThrustSpeed`、Starfall柱数阶梯／512人、Helix／Dome人数份额和上限配置已退出使用；固定参数不继承旧配置。保留存档、死亡／HP、增长及伤害配置。

权限2命令：`/cmi particle allaystorm [count]`、`stop`、`status`。初始count与增长上限分开，硬上限131072。

## 完成与观察者恢复

Helix按碰撞后的成员实际位置越过冻结终止平面完成，不再由参考进度提前释放；当帧收剑并关闭接触。发射中首次确认地形裁剪开启0.5秒观察窗：累计裁剪至少0.1秒、预期正轴向推进至少0.05格且实际净轴向推进低于预期10%时，该成员无伤害退出并普通归队，不等待全波截止。轴向使用冻结单位轴，侧向滑动不算前进；未知覆盖、脱嵌、新攻击、阶段切换、死亡与完成清空窗口。起步或短暂擦碰不能仅凭低速触发退出，仍有有效轴向推进者继续攻击。参考进度仅提供导航，最终故障回收为理论尾部通过时间后1秒。Dome与Helix共用死亡rank完成、预留释放和广播路径，死亡成员不会在尸体消失后重新进入集结分母。

Starfall中途观察者先等待按需实际状态快照，再从已有集结／下降／展开／短回流阶段继续；延迟追赶期间无伤害，不补播触地声。所有有效模拟来源离开时结束旧柱并释放成员，返回后正常调度。正常有观察者时的固定64名、触地判定和0.5秒短回流不变。
