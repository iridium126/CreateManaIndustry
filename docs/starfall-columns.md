# Starfall：单柱星雨（2026-10-18）

当前运动、8192人Dome、集结反馈与协议11布局见 [协议11交付说明](allay-storm-v11.md)。历史版本段落用于追溯。

状态：实现、服务端与离屏验证完成；客户端实机观感、多人帧率和真实地形由用户验收。核心协议 **11**，服务端和客户端必须同时升级。

## 调度与迁移

每个风暴拥有独立64个星柱槽，以及原有4个天穹／双螺旋槽。所有攻击共享成员预留，每柱固定64名存活成员。死亡不补员；成员不足、容量满或无安全落点时跳过，不积压请求。仅0.5秒专用短回流期间仍占柱槽和成员；之后释放并普通归队。

| `allay_storm` 配置 | 默认 | 范围／含义 |
| --- | ---: | --- |
| `stormStarfallInterval` | 0.5 | 0.05–60秒；按game tick调度 |
| `stormStarfallChance` | 0.5 | 每名符合条件玩家独立抽签 |
| `stormStarfallColumnMembers` | 64 | 固定64，匹配四股环绕／独立展开队形 |
| `stormStarfallMaxActiveColumns` | 64 | 1–64，包含0.5秒短回流中的柱 |

旧 `stormStarfallMembersPerColumnStep`、`stormStarfallMaxColumns`、`stormStarfallMembersPerColumn` 退出配置；旧512名配置不继承至新队形。存档、死亡／HP、增长定义和 `stormWaveDamage` 保留。

Helix和Dome各自按每场风暴默认每30秒独立50%抽签，Starfall保留自己的每玩家抽签。详见 [协议10改造](allay-storm-v10.md)。

## 落点与几何

玩家必须存活、非旁观者、同维度、处于活动跟踪状态、头顶露天且XZ位于当前风暴半径内。按UUID排序后轮换起点遍历，避免容量竞争时固定优先。

落点优先使用触发时玩家XZ，生成后冻结，不追踪玩家。已有柱从集合至绽开结束预约中心周围8格间距，归队时释放落点预约。拥挤时按向外优先、偏转 `0,+15,-15,…,180°`、整数偏移半径1至风暴直径搜索；中心处方向由种子决定。最终网络浮点坐标也参与间距验证，避免远坐标舍入后重叠。柱中心必须留在冻结的风暴半径内，星花可越过边界4格。

只进行落点中心地面定位，要求有限高度、非流体支撑、集合高度在地面之上；不再要求整片平整、扫描全部通道或周期复查。允许坡地／台阶／动态障碍，局部成员由客户端碰撞裁剪、滑动与脱嵌。触发者离开或死亡不取消柱；停止或换代释放身份与成员。

## 阶段和视觉

1. **集合：** 集合中心仍为主体下方8格。64名成员分四股绕柱飞行，每股16名；轨道半径0.9–1.2格，纵向间隔0.7格，总高度10.5格。轨道角速度0.7弧度／秒。从当前GPU位置、速度平滑汇入移动轨道，集合末段提前衔接下降切线，计入下降速度后立即进入下降。
2. **下降：** 保持空手和环绕飞行，转速平滑减弱并分流至各自触地点。64个触地点分布于半径1.4格的圆盘内，使用互异角度与等面积半径，避免共同挤向中心；名义抵达时间每名错开0.06秒。实际触地确认后立即展开，不等同组成员或名义时间。无数据时继续视觉运动、不等待，未确认触地者无伤害归队。
3. **绽开：** 每成员拥有独立方向，取消八条共享路径。各自从实际触地点以三维弧长6格／秒展开，取消固定1.5秒缓动；半径增至4格，参考面满足 `h = 0.0625 r²`；外缘高1格。仅该阶段持钻石剑、产生接触候选。先落地者先展开，形成连续向外流动的星雨，而非整组同步弹开。
4. **归队：** 结束伤害并收剑，从当前位置和速度执行0.5秒平滑短回流，再释放并交给普通归队。普通成员始终保留盘旋目标，不能被攻击路径覆盖到原点。

星柱使用连续渲染时间，避免只在20Hz游戏tick跳变时更新目标；轨迹采样不再叠加可变帧长前瞻。MODEL使用稳定飞行姿态与绕柱切线朝向，下降末端平滑转为径向朝外，避免低速时在速度朝向与随机待机朝向间切换。原生、阴影与Iris共用该姿态逻辑，持剑／接触读取归一化展开进度。

下降初始化一次弧长表，GPU只查表推进。下降／展开／回流6格／秒，跨阶段剩余时间同帧传递；展开后立即回流，不以整柱剩余寿命拉长。下降末端切向接入参考曲面，回流方向连续转向当前盘旋目标。实际碰撞拥有最终移动结果，允许偏离冻结参考抛物面、降低实际速度，不停止阶段进度等待参考点。

每柱128个浅青柔边六边形粒子构成半径4格的空心预警圈，位于地面上方0.20格。单粒子完整边长约0.09–0.18格，为旧版的一半。集合低亮呼吸，临近地面提亮，GPU确认触地后短促青白脉冲。攻击结束或中止后0.25秒淡出。保留深度遮挡，不投影，不增加装饰MODEL替身。

触地声来自GPU确认反馈，按柱合并，每客户端每game tick最多2声；音效反馈只在客户端消费，不发送为伤害请求。全部星柱与主体共用独立的风暴区块段碰撞域，不再占通用粒子8槽。

## 同步与信任边界

新增 `storm_column` S→C消息，含dimension、epoch、24位柱ID、种子、冻结落点、集合高度、风暴边界、阶段时间和64名成员名单；只有开始／观察者补同步发送完整快照，中止为紧凑事件，无逐帧位置包。

GPU槽0–3保留给大招，4–67为单柱。归属使用独立高位标记与6位柱槽，圆环ID使用独立编码，避免32位掩码和旧两位槽产生别名。接触按成员当前归属直接查找柱，不循环64槽；沿用按身份／攻击ID去重存储，不按64槽扩展。双bank域总计 **7,484,800字节**，首次活动攻击时按需创建，沿用SSBO 26–28及Iris TBO unit 14。

GPU实际触地门控、粒子内绽开标记、MODEL持剑分区、原生／Iris姿态和阴影读取同一提交。实际触地未确认、局部碰撞未知、非绽开或旧柱不报告伤害；圆环不足128粒子仍允许有效接触。

`storm_wave_contact` 保留dimension／epoch／攻击ID／采样时间／成员和绝对接触点。协议10沿用对客户端实际阶段的信任，不再重复检查采样时效、历史位置、包络或地形。服务端验证活动身份、名单／存活、有限数、攻击未释放及按玩家／成员／攻击去重，再调用原版hurt。近战改用attackSeq，详见 [同步协议](allay-storm-sync.md)。

保留既定边界：成员位置、实际集合和触地、命中候选由GPU客户端提供；服务端做合理性验证及最终战斗结算，未新增成员位置模拟。

```powershell
.\gradlew.bat test check --offline --console=plain
.\gradlew.bat -I scripts/allaystorm/gametest.init.gradle runGameTestServer --offline --no-configuration-cache --console=plain
.\gradlew.bat -I scripts/particles/validation.init.gradle validateStarfallColumnGpu validateStarfallGpu validateDomeGpu validateHelixGpu validateModelPopulationGpu validateModelShadowGpu validateModelShadowIrisGpu --offline --no-configuration-cache --console=plain -PbenchmarkOutput=build/benchmarks/storm-v9-final
```

单元测试包括几何／速度／接缝、落点搜索、成员互斥、64槽与4槽隔离、旧事件和协议。专项GPU测试以远坐标64柱／4096成员验证抛物线、实际集合／触地门控、持剑和阴影、区域接触、去重及128粒子圆环。Iris transform-feedback额外对照槽67的下降／绽开姿态。

64柱性能CSV只包含固定输入的生产update内核，三轮、每轮40次预热和120样本；不含完整世界帧、服务器落点搜索、网络、真实光影包或全部MODEL绘制，不能据此推导游戏帧率。原始输出在 `build/benchmarks/storm-v9-final/`。

协议9最终自动化结果、性能变化和未完成项目见 [本次实现与验收记录](allay-storm-v9.md)。旧协议8基准保留在 `build/benchmarks/starfall-orbit-final/`，不代表当前结果。

客户端实机由用户完成：

- 检查环绕集合与下降时身体、头部和翅膀无高频姿态闪烁；先触地者立即展开，中心没有64名成员完全重叠，归队无二次出剑。
- 两端升级后，在远离原点的开阔平地创建风暴，观察集合位置始终在主体下方8格，主体不偏航；等待完整首轮后检查持续单柱节奏。
- 站立与移动、多人聚集和风暴边缘：落点冻结、中心间距至少8格，外扩搜索不越出主体半径，天穹／双螺旋仍独立出现。
- 对照下降空手无伤害、接地后钻石剑／逐成员独立抛物面展开／区域接触、外缘4格高1格、归队收剑无伤害；检查各接缝和回流不突跳。
- 检查半尺寸粒子仍能辨认，圆环空心、不漂移、不穿墙，近地提亮及触地脉冲不洗白画面，音效无堆叠。
- 屋顶、台阶、流体、动态方块、触发者离开、停止重建、换维度和重载；检查碰撞未就绪及旧圆环不会造成伤害。
- 无光影及实际Iris／Sable光影包，第一／第三人称和其他玩家视角，确认持剑、身体与阴影一致并记录多人帧率。
