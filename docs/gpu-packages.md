# Create GPU 包裹：当前实现

更新：2026-10-04。自由包裹从创建起保存为服务端轻量记录，只由 GPU 进行运动模拟；没有就绪 GPU 时保留最后确认状态并暂停。关闭 GPU、资源重建、历史缺失或区块卸载都不会恢复自由实体或启动 CPU 后备物理。锁链包裹仍由服务端按 tick 执行最小物流逻辑。

## 当前契约

- 服务端以身份、租约、区域和模拟步号校验 GPU 权威。掉线时优先迁移到其他就绪客户端，否则暂停；环境、几何或候选预算暂不可用时只暂停受影响包裹，保留最后有效姿态并重试。
- 生产物理只保留 `linked` 空间索引。历史按单调采集步编号保存；Minecraft 客户端仍以最多 20 次/秒采集时，200 tick/s 将每次实际观测拆为十个有界游戏步，移动结构姿态按区间插值。缺失历史不能伪造补算。
- 水、火、熔岩与机器接触由 GPU 扫掠检测；服务端验证精确生命周期、接触点和伤害资格，再一次性提交环境效果或机器库存事务。队列积压保留待确认 journal。
- 成对 CCD 按相遇路径上的实际有向位移扩展候选范围，覆盖垂直和横向交叉轨迹。环境捕获及 ACK 各有独立处理额度；未捕获的相同连续接触可合并，但保留每步伤害计时。服务端按已确认姿态回收越过虚空阈值的记录。
- 溜槽、传送带、漏斗等输出先按包裹尺寸移出源机器，再进入统一轻量记录入口。过滤、部分接收和完整消费均由服务端处理；部分接收写回剩余物品，成功消费后才退役 GPU 槽位。传送带库存同步不会反复撤销不变的碰撞几何。
- 自由包裹区域迁移只关闭旧区域通道；其他区域共享的模拟历史与 GPU 资源继续工作。锁链在 CPU/GPU 切换时按确认进度和事务序号保持物流一致。
- Iris 主相机锁链包裹按所属传动轮的原生渲染器距离与离屏规则准许，兼容 Sodium 独立的全局方块实体集合；Sable 使用父结构渲染帧中的局部相机检查距离。阴影独立使用 Iris 准许的传动轮列表。见[可见性与日志修复](gpu-package-shader-log-fix-2026-10-04.md)。
- 传动轮移除或变形会立即撤销该轮的客户端绘制准入，由服务端按轨道退役其租约并回传确认姿态；不会因此暂停共享 GPU 会话中的自由包裹或其他传动轮。
- 自由与锁链使用独立时钟和渲染插值；自由场景等待几何或力输入时，锁链继续推进。
- 自由包裹由 `PackageLightObserverClient` 呈现，协议为 `gpu-packages-13` / `gpu-package-observers-5`。暂停时显示最后确认姿态；普通与 Iris 渲染使用一致的面亮度规则。
