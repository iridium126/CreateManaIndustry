# 悦灵原点地形与喀斯特拱桥

按确认采用**内半径100、外半径200格**。这两个值是自然岩壁的基准半径；侵蚀轮廓会偏离基准，但不会切入半径90格的平台。

- 地表方块 Y=95，其顶面直接接世界树模型的首层 Y=96。半径90格内严格保持该地表高度。
- 半径500格内为低起伏地形；峡谷外围至220格保持95，随后逐渐加入最多约4格的缓坡。
- 半径500～700格采用五次平滑插值恢复原始地形，700格外不改动。外缘低于海平面的部分保留水体，避免海洋边界形成竖直水墙。
- 环形峡谷基底最低 Y=-5，即相对地面深100格；底部有起伏和崖脚堆积坡。岩壁叠加纵向溶沟、岩层、三维侵蚀噪声和悬挑，材料为滴水石、方解石和安山岩。
- 桥面 Y=95，十条径向石砖通道连接内外岸，中段由环形廊道互连。径向桥宽约4～8格，环廊宽约5格。砖面掺入模型生成的苔石砖。
- 径向桥在约100、150、200格处设置桥台/桥墩；两孔净跨约50格，拱腹抬升33格。环廊按十个交会节点分孔，抬升38格。交会处桥墩深入基岩，拱上保留实体砌体。属于依据拱桥构造的体素建筑，未进行工程有限元计算。
- 岩壁与桥拱下生成附着藤蔓和发光浆果，底部、台地、桥面边缘生成苔藓、花草和杜鹃；宽阔、具备根部支撑与净空的岩台/地面生成小树。桥面中央保留连续净空。
- 圆环内半径100格以内和外半径200格以外的 Y=95 地面不再添加这套自定义地面植物或小树，交给生物群系自身的装饰；岩壁低处藤蔓、拱顶、桥面、环谷底部等其余装饰保持不变。
- 原点水平距离200格以内过滤 `minecraft:lake_lava_surface` 的写入，200格外仍按生物群系原有配置生成。过滤发生在特性写入方块时，因此跨区块扩散到禁区的熔岩也会被阻止。

## MarkovJunior 模型

`src/main/resources/data/createmanaindustry/markov/karst_causeways.xml` 在121×161×1网格执行：X对应90～210格半径，Y对应周向角度，最后一行是周期接缝的重复行。

参考 `.refs/MarkovJunior/models/RegularPath.xml` 的规则端点格网，以及原版 `all` 和 `prl` 语义：先每16格播种端点，再长出径向路面、连接各交点，最后随机风化铺装。使用项目已有的 `MarkovModel` 执行器，无新语义扩展。

Java 将输出极坐标映射到世界，加入小幅曲线、桥宽和有桥台约束的拱腹。模型负责通道拓扑和铺装，连续几何场负责拱桥实体及喀斯特侵蚀。世界种子决定整体朝向、曲线、风化与地貌；不依赖区块生成顺序。游戏无需.NET、参考仓库或预生成模板。

## 生成阶段

`AllvrChunkGenerator.applyCarvers` 在原版雕刻后塑造地表及峡谷，因此生物群系装饰读取修改后的高度图。原版装饰后恢复环内空腔和桥体、添加专用植被，最后由现有世界树生成器放置树体。

所有写入仅限当前区块。跨边界小树从一致的世界坐标格网选取锚点，各区块写入自己的部分。中央带外的Cube生成不变。

**仅作用于新生成的区块，不重写已有存档。** 原点通常已经生成；查看完整效果应使用新世界，否则新旧区块边界可能仍保留旧地形。

## 验证与复现

```powershell
./scripts/markov/validate-causeways.ps1
./gradlew.bat test --tests '*AllvrSanctuaryTest' --offline

python scripts/prepare-allvr-worldgen-test.py
New-Item -ItemType Directory -Force build/sanctuary-test-run/mods | Out-Null
Get-ChildItem -LiteralPath run/mods -Filter 'owo-lib-neoforge-*.jar' | Copy-Item -Destination build/sanctuary-test-run/mods
./gradlew.bat -I scripts/sanctuary-test.init.gradle runGameTestServer --offline

./gradlew.bat build --offline
```

原版C#解释器与Java执行器对比种子0、1、42、137、2026、-1及32位整数上下界，全部逐格一致。三个单元测试覆盖平台/过渡边界、实际方块桥面四邻接连通、十个桥头、挖掘深度、树根保护及桥墩落地。

`build/causeway-validation/top.png` 与 `cutaway.png` 为实际几何场的顶视图和剖切投影，未显示植物、世界树、游戏材质和光照，不能替代客户端观感验收。

隔离GameTest使用真实方块注册表和ProtoChunk检查生成结果，覆盖平台、空腔无流体、桥体、步道净空、植被、重复生成一致性与700格外保持原貌。该测试不加载或更改玩家存档。

2026-09-17 实测：GameTest 1/1通过，比较424,960个方块；采样区块中统计到106,002个空气方块、1,730个完整/苔石砖方块及940个藤蔓/浆果/草蕨方块。统计仅用于验证样本确实覆盖相关内容，不代表整个峡谷的总量。
