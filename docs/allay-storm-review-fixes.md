## Starfall 期间主体移向世界原点

根因在 GPU 转向覆盖：`cmiStarSteering` 对不属于攻击名单、尚未开始、已结束或中止的成员提前返回时，未赋值的 GLSL `out` 参数仍会写回调用方。原调用又把主体盘旋目标同时作为输入和输出，因此主体目标/前馈速度可能变成未定义值（实测驱动可表现为向零点转向）；服务端追击中心并未因此移动到零点。

修复包含两层约束：函数所有退出路径明确给出目标、速度和阶段；调用方使用独立临时输出，仅在成员确实参与攻击时替换主体盘旋目标和轨道速度。

独立 OpenGL 回归直接运行生产 `update.comp`，在 `(1500,128,-2300)` 和 `(-1700,192,2100)` 附近对比攻击开启/关闭时的 65 个成员，分别选择 1、32、64 人参战。未参战成员及开始前、截止后、中止时的成员，其位置和速度必须与普通盘旋完全一致；同时确认攻击名单仍会转向。直接调用转向函数还检查非名单成员的全部输出均已定义。

修复前该回归在下降阶段 `time=12`、未参战成员 1 上失败，修复后通过。自动化运行使用隐藏 GLFW 上下文，不启动 Minecraft 客户端、不修改游戏世界。

共享转向回归结果：Starfall GPU 1,288,056 项断言、Dome GPU 8,755,139 项断言、Helix GPU 6,934,061 项断言全部通过。
