# MODEL 合并阴影质量与性能

本页保留历史七档方案与测试证据。当前投影和接收选项见 [客户端配置](particle-engine-install.md)。

状态：七档配置、风暴整体剔除、投影延伸体视锥测试和专用阴影顶点上下文已实现。新增原生深度内核、历史可靠性过滤、CPU 直传独立候选及 BSL 前向免接收适配。补全计划**尚未全部完成**；逐包缺口与证据边界见 [实施矩阵](particle-shadow-completion.md)。深度未获生产资格；未知或失效材质继续原生合并并接收阴影。Minecraft 客户端由用户验收。

## 配置与实际行为

客户端 TOML：`[allayStorm] shaderPackShadowQuality = "FULL"`，默认 FULL。

| 档位 | 主体整体剔除 | 成员投影视锥 | 请求的深度阶段 | 当前有效深度行为 |
|---|---|---|---|---|
| FULL | 无 | 原 Iris 规则 | 无 | 原生 |
| COARSE | 有 | 原 Iris 规则 | 无 | 无 |
| FRUSTUM | 有 | 有 | 无 | 无 |
| SHADOW_HIZ | 有 | 有 | 当前阴影图 | 几何回退 |
| SCREEN_HIZ | 有 | 有 | 历史主深度 | 几何回退 |
| COMBINED_HIZ | 有 | 有 | 阴影图，再历史主深度 | 几何回退 |
| OFF | 不准备、不绘制合并 MODEL 阴影 | — | — | — |

组合档界面显示 `SHADOW_HIZ+SCREEN_HIZ`。档位同时覆盖风暴、普通 MODEL 与持剑。羽毛与远景 LOD 始终不投影；不抽样、不交替帧、不修改模拟或主画面数量。设置在帧边界锁存，切档时作废已有整帧测量，避免混合档位统计。

FULL 以下请求悦灵、普通 MODEL、羽毛、LOD、持剑不接收场景阴影。固定源哈希匹配的 BSL 10.1.1 已加入原生前向适配：只替换场景／云影可见性函数，保留方向光、透明混合和编码；在合并编译阶段预备低档程序，切档不首次编译。其余七包仍有未完成的原生／deferred／透明契约。诊断按包报告具体原因。**适配失败只保留原生合并与接收，不触发自绘回退。** 普通合并程序编译失败的恢复行为不变。

客户端分类为 rendering、particles、allayStorm、hexcasting、packages、greatTricks、allvr。分割与同命容量属于 greatTricks；风暴羽毛／金币速率和 LOD 距离属于 allayStorm。没有旧键别名或迁移；除新增档位外，默认值与范围保持。

## Iris 基础规则

依据本地 `.refs/Iris/common/src/main/java/net/irisshaders/iris/shadows/ShadowRenderer.java` 及 `shadows/frustum/advanced/`，不依赖网上其他版本：

- 原生实体阴影开关、实体阴影距离倍率与实体自身距离判断先限定候选。距离盒围绕相机，是轴对齐范围，不等同于阴影图矩形或主相机视锥。
- `AdvancedShadowCullingFrustum` 使用主视锥和朝光源方向扩展的平面集合，容纳屏幕外、仍能向画面内投影的物体，不能替换为普通相机六面剔除。
- `SafeZoneCullingFrustum` 先施加外层距离盒，在其内取安全区盒与 Advanced 结果的并集。安全区服务于 voxelization 等包内效果；不能误写成两者的交集。
- 包要求距离模式或检测到体素化时，Iris 可以禁用 Advanced，仅保留距离限制。`CullEverything` 全拒绝；`NonCulling` 无附加平面限制。现有 `PackageShadowPolicy.copy` 保留这些语义。

FULL 沿用既有 MODEL 尺寸、实体距离、距离盒、SafeZone 并集、最多 13 个 Advanced 平面和持剑条件。中间档在基础规则后增加主画面潜在投影可见性测试，因此**可能减少屏幕外体素化、间接光和体积效果**，这是所选性能取舍。它不是与 FULL 等价的优化。

## 风暴整体与逐成员剔除

`ModelShadowGroups` 管理双 bank 专用索引，绑定 30；29 仍为现有间接调度资源。没有改变人口索引 ABI 或其他消费者。分组写入复用 keygen 的 MODEL 索引遍历，不新增全池扫描。

圆柱采用更新输入阶段冻结的风暴中心与 `R=max(2,radius)`，经 `StormShadowSnapshot` 绑定候选代次；索引生成不再读取较新的实时圆柱。水平半径 `1.15R+0.4`；带宽半高 `clamp(0.4R,3,8)/2`，下界 `-1.6-band`，上界 `clamp(0.2R,2,6)+band+0.4`。每个 MODEL 使用包含姿态、羽翼和持剑余量的 `8*max(startSize,endSize)*scale+1` 外包范围；只有风暴成员整个外包范围严格位于圆柱内才归主体组。跨界成员、离群攻击者、普通 MODEL 都进入其余组。

在 CPU 只对一个圆柱作几何预判。上一阴影矩阵仅用于预测是否值得维护分组；它从不授权最终剔除。预测可见时停止本帧专用分组，预测失准只会漏掉一次优化。GPU 阴影准备阶段用**当前真实光线方向**重测已提交圆柱沿光线延伸的体积；只有整体不可见时才把间接 dispatch 改为“其余组”的长度，完全跳过主体组逐成员尺寸、持剑及可见性工作。圆柱部分可见时保留全部组。

成员视锥测试对完整 AABB 沿远离光源方向的半无限射线求保守区间。各平面可使用不同支撑点，可能多留对象，不会仅因原物体在屏幕外就删掉它。矩阵非有限、分组缺失、计数溢出或代次不一致时回到原人口索引路径。分组和粒子／人口索引同代提交；失败候选不发布。FULL、OFF、无光影或无活动风暴时不维护专用分组；首次有效提交前沿用原路径。

双 bank 最多分配 `2*(64+8*262144)` 字节，约 4 MiB。诊断显示的是分配大小，不代表驱动物理驻留。离开世界释放；切到 FULL/OFF 保留已分配容量以免反复分配。

## 深度策略与未启用原因

旧通用原型保留在 `scripts/particles/experiments/shadow-quality/`。新增 `ShadowDepthPyramid` 直接读取原生深度，首级归约不做全尺寸复制，独立非比较 sampler 不改 Iris 纹理状态。`shadow_depth_test.glsl` 实现完整区域查询、NPOT 分区映射和 identity/quartic/euclidean 区间包围；未支持的非线性模式保留候选。可选内核独立于 FULL 编译。

CMI 阴影入口直接传入当前 `ShadowRenderTargets.getDepthTexture()`，不使用入口后复制的 opaque-only 快照。`beginHand()` 已接入历史观察边界，但尚未接通可信静态接收面标记及实际捕获发布。`ShadowHistoryGpu` 在隐藏上下文验证了双 bank、GPU 重投影、孔洞／置信边缘保留和失败不发布；其测试标记是合成输入。生产没有经过验证的偏移／滤波／副作用契约和历史标记，因此不分配深度层级。三个深度档仍几何回退，不能视为已启用或已完成原生整链资格测试。

性能优先的后续候选仍可比较接收面分块／稀疏网格、包专用阴影空间包围体、现有地形深度的低分辨率保守测试。历史接收面网格尚未进入生产。任一方案都需计入捕获、构建、查询和失效成本；组合策略不能仅凭两个独立阶段有效便启用。

## 等语义绘制与 CPU

`ShadowVertexContext` 只把 CMI 自有输入声明中的 shadow=true、feather=0、LOD=0 固化，供编译器消除主画面淡出和无关分支。不重写包内 shader，保留 native fragment、alpha、畸变、输出编码与其他可观察效果。检测到 geometry/tessellation 或 image/atomic/SSBO/barrier 上下文时保留原输入。八包均链接；七包实际栅格逐位对照，Solas 的 image 副作用触发原路径保留。

渲染线程复用阴影矩阵、视锥数组，缓存 uniform 位置，复用已捕获图形状态恢复 RenderSystem 缓存，保留 Iris apply/clear 与状态边界。没有逐成员 CPU 遍历、可见性读回或同步等待。

去掉内外层重复资源快照的候选，三轮 CPU 微基准约省 0.0014 ms，未超过 0.002 ms 绝对门槛，**生产仍使用完整资源快照**；`PackageRenderState(false)` 仅供离线实验。工作组批量预留实例也只留在验证脚本，未启用。

## update.comp 的 16 块与纹理

生产绑定仍由 `ParticleBuffers` 常量和 `ParticlePrograms.commonPrelude()` 生成。绑定编号上限与每着色阶段活跃块数量是两件事：编号 31 并不意味着该着色器有 32 个活跃块。

| 绑定 | update 活跃 SSBO |
|---|---|
| 0 / 1 | 粒子读池／候选写池 |
| 3 / 5 | 候选计数器／Emitter |
| 11 / 14 | BakeMeta／已提交计数 |
| 13 / 16 / 18 | 网格与羽毛状态／伤害队列／玩家快照 |
| 19 / 21 / 31 | 位置修正／成员映射／稳定身份 |
| 24 / 26 | 已提交人口索引／Starfall |
| 27 / 28 | Storm 状态读／候选状态写 |

候选人口成员和 MODEL 分配器继续使用 r32ui image buffer；动画读 TBO、动画写 image、离线导航与碰撞纹理保留。维持原 image/storage/texture/indirect 各视图 barrier、更新域顺序、双 bank 和失败不发布契约。

`UpdateStorageGpuValidation` 实现了计划中的 0–15 重新编排：合并 BakeMeta、玩家、伤害为只读帧输入，腾出两块改写候选成员和分配器 SSBO，实际链接活跃块为 16。按稳定身份逐位对照通过。仅内核、尚未计入合并输入成本时，65,536 风暴约 0.465→0.811 ms，131,072 约 0.846→1.557 ms；混合负载约慢 67–77%，普通 MODEL 约慢 11–17%。因此拒绝替换，生产 update GLSL 保持冻结基线内容。脚本用 GPU-copy 打包测原型总链，**不是已实现 CPU 数据直传**；不拿首次冷编译与缓存命中编译比较。
