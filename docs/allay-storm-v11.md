# AllayStorm 协议11：连续星柱、外缘集结与8192人厚壳星潮

2026-10-19。核心协议10升至11；客户端与服务端必须同时更换JAR。GPU提供运动、实际触地及接触候选，服务端负责名单、生命和最终伤害；没有新增服务端成员位置模拟。真实客户端观感、复杂地形和多人帧率由用户验收。

## Starfall 修复

新增生产 `update.comp` 完整生命周期回归，修复前在下降开始约0.13秒时测到成员距柱轴仅0.443格，并触发失败。旧笛卡尔补偿会抵消横向半径。下降改为从实际位置、速度初始化的柱坐标曲线，保持四股绕柱与纵向错位；弧长进度、跨阶段剩余时间、实际触地门控和0.5秒短回流保留。下降位移按弧长步长归一化，避免稀疏弧长反查产生速度带。

渲染读取提交后的实际阶段标记：集合3、下降4至5、短回流5、普通归队6；绽开仍为负标记。原生MODEL、阴影和Iris共用读取，不再由名义触地时钟推断姿态。延长服务端保守截止余量，避免正常下降被整柱超时打断。

## Helix 与集结反馈

Helix仍固定4096名，存活16384、对向两臂各2048名未预留成员才发动。模板、64格长度、32格尾部外包络、12m/s集结上限及既有突刺速度配置保留。

锚点水平偏移为生成时风暴半径，主体中心下方8格；水平朝向及半径生成时冻结，只随主体平移。取消额外50格偏移。集结期间每5 tick更新三维朝向，保持8度/秒限制；发射后冻结路线。

新增 `storm_attack_gathered` C2S，携带dimension、epoch、攻击ID。实际碰撞处理后，成员距目标不超过0.4格、相对目标速度误差不超过1m/s，连续3帧计为就绪。所有未完成存活成员就绪后，权威客户端复用现有异步接触回读发送聚合反馈；服务端验证活动身份和权威角色后，下个tick立即LOCK。等待期间保持运动，超时中止，不发射未完成队形。观察范围不再阻止权威客户端读取集结与完成反馈。

## Dome 厚壳星潮

固定8192人，存活人数至少16384；选员可来自任意旋臂，扣除死亡及所有攻击预留，不足则消耗机会并跳过。默认独立每30秒50%，4个共享大招槽与64个Starfall槽不变。`stormDomeMemberFraction`、`stormDomeMaxMembers`退出配置规范，不再读取。

生成时固定玩家XZ和身体中心高度；原目标移动、离开或死亡均不改变已生成区域。成员直接以最多12m/s集结到上半球厚壳，合法半径16至32格。删除旧六瓣、顶冠、主体处集合、整队接近、预警折叠和专用升空回流。

成员同时开始运动，沿61条稳定旋入通道以弧长6m/s推进，由不同初始弧长错开中心区抵达。每通道1024个近似等弧长节点及其实际累计弧长，所有大招共享一份模板，不逐帧上传。完整8192人资源1,130,512字节；最晚59.917秒结束。参考终点位于6格中心区的穿越平面，成员结束后立即关闭攻击、释放预留并继承实际位置、速度普通归队。

生成器 `python scripts/allaystorm/generate_dome_template.py` 使用NumPy/SciPy，仅离线运行。候选经过整个运动区间的冲突图筛选，在0.025秒区间内再按双方节点拆分，求每段相对线性运动的最近距离，并留0.0005格数值余量；完成时截断区间，已结束成员不留在终点充当障碍。最终8192名初始最小参考间距约1.4005格，验证阈值1.4格；实际初始采样半径约19.793至31.371格，位于16至32格设计范围内。该模板是离散通道排布，并非填满每个半径的实体球壳。参考间距不保证受动态地形挤压后的实际模型间距。

Dome与Helix共用持剑标记：仅攻击阶段，成员身体中心距任意存活非旁观玩家身体中心严格小于6格时持钻石剑并允许接触；达到6格收剑。模型维持原尺寸，移除额外整身持剑倾斜以保持身体、翅膀的1.4格模板间距；武器本身不计入身体防重叠包络。伤害仍由既有配置决定，盾牌、护甲和原版无敌帧保留。

## GPU 布局与生命周期

波次312 words布局和绑定保持。Dome带模板版本，使用单组8192名单。`storm_attack_completed`扩至128个long；GPU大招每槽256个uint、星柱每槽2个uint，共1152 words，统一索引函数。三帧就绪计数按稳定成员身份保存，只读取当代结果；每帧聚合计数清零。

Dome模板每GPU数据银行只上传一次；独立于Helix模板及普通归队确认位更新，避免新Helix重复上传Dome资源。完成状态补发给观察者，旧完成反馈不能释放新归属。中止、超时、死亡和普通归队的独立碰撞覆盖沿用专用域，不占通用粒子8槽。

## 验证与用户验收

生产GPU覆盖不同帧率Starfall完整生命周期、Dome8192人的集合就绪及逐成员完成、Helix接触扫掠与第100名玩家，以及原生MODEL/阴影/Iris一致性。服务端GameTest覆盖固定人数边界、独立调度、冻结中心、旧身份拒绝、反馈锁定、逐成员释放、其他玩家受击和无敌帧。

失败基线：`build/storm-v11-starfall-baseline.log`。完整回归见 `build/storm-v11-release.log`，配置语言资源更新后的最终构建见 `build/storm-v11-package-final.log`。固定输入工具只记录局部CPU/GPU耗时，不代表游戏帧率、真实世界采集预算或多人网络体验。

用户实机项目：星柱不收束为竖线且连续触地展开；Helix新锚点与集结等待；Dome远景厚壳、连续旋入及密集中心区可读性；斜坡、墙体、动态编辑；多人和光影包帧率。上述项目尚未自动完成。

静态生产核集结对比（相同4096名初始主体成员、固定目标、无世界障碍）：旧偏移位置10.133秒达到就绪，新外缘下方位置4.467秒。该数据验证位置与就绪机制的效果，不代表移动目标和复杂地形的实机集结时长。
