# Dome v4／核心协议14：平滑贯心与错落星流

实现与自动化验收已完成；真实客户端观感、复杂地形及多人帧率由用户验收。客户端与服务端必须同时替换JAR，协议13客户端不能混连。完整机器可读结果见 [验证数据](allay-storm-v14-results.json)。

## 行为与修复

保留12288名成员、16384存活门槛、95%集结就绪规则、独立调度、冻结中心、十二重星幕、768条贯心通道和穿出三格后的普通归队。未就绪成员照旧释放，服务端不模拟成员位置，伤害、防御及成员去重规则保留。

集结使用66条确定性的三维闭合流线；同流线等弧长排列、同速飞行，不同流线速度4.050–5.961格／秒。位置扰动上限实测0.455格，保持16–32格上半球厚壳；顶部参考位置31.630格。速度、旋向和起伏由稳定种子确定，不逐帧随机。

修复LOCK循环映射在负方向及首尾边界出现重复通道的问题：GLSL只对非负整数取余，再明确恢复floor-mod语义。生产GPU回归检查所有流线、正反方向及多个LOCK时刻的通道唯一性。集结反馈在最终几何审计后从位图归约计数，避免计数与实际名单不是同一快照。

经历过集结的客户端收到LOCK时，捕获当前实际环流相位，使用本地连续交接时钟；重复快照不重启攻击，槽位回收和换代会清理本地时钟。没有旧集结状态的观察者仍使用同步攻击时钟。服务端身份和截止时间不变。Dome另用提交帧的短相对时钟，避免长世界时间和29.13小时时钟环绕时丢失帧内时间精度。

相位接缝采用1.25秒C2补偿；实际位置、速度误差另在一秒内连续接入，不停车、不跳回模板。集结和攻击复用已求出的目标及前馈速度，删除就绪检查中的重复轨迹查询。攻击稳定段以6格／秒为目标，实际导航限制加速度18格／秒²、转向180°／秒；碰撞可以降速。

## 离线资源与运行时职责

编码资源使用分段五次Hermite曲线和离线逆弧长表。GPU仅查表和求值多项式，没有逐成员高斯积分或Newton反解。资源22,912,528字节，SHA256：

`53456dfd103eb61f5f7dec5022d33f1d2eaf06adfa2ed584e0d4ffcf27f1fe94`

最终binary32资源重新解码后，连续证书给出：体心间距至少0.50172格、加速度至多17.6973、jerk至多111.401、转向不超过π弧度／秒；0.5秒时最小向心速度3.1487格／秒。少量允许低于中心平面的通道保留。

同次Dome内部的正常运动完全由烘焙负责，不再运行普通boids或八轮位置投影。运行时为集结接近、跨攻击及归队避让建立一次候选网格，选择一次最危险的实际预测接触，再应用一次有界速度／扫掠裁剪；少量无解成员走短名单，数量较多时才查询空间网格。不把不会相撞的邻近通道当作障碍。原地重合使用稳定成员身份决定分离方向，严重地形阻挡0.5秒无伤害退出。

跟随标记采用0.04／0.10格滞回和连续三帧进入条件；真实纠偏才退出，单个浮点ULP的往返误差不会清除跟随状态。普通归队继承实际速度并限制转向，避免未参战成员突然反向穿入后续星流。

形式化资源证书覆盖编码的基础曲线和闭合环流，不代表所有动态地形、任意初始状态或任意多攻击交叠的全局网格不相交证明。实际相位交接与异常处理另以生产GPU生命周期测试验证；实际模型顶点和复杂地形的视觉验收仍留给用户。

## 共享姿态

每个稳定成员两个32位字：yaw／pitch各16位，另含有效位、15位速度、16位手臂混合量。0.12秒响应及180°／秒上限，近竖直／低速保留有效朝向。剑显示和伤害资格仍严格由攻击阶段及六格距离决定，手臂混合不延长伤害。

双缓冲新增2MiB，首次Dome时才扩容；归队后平滑交还普通姿态。原生MODEL、阴影和GLSL330 Iris读取同一提交缓存。Iris保留TBO单元15，渲染边界保存／恢复10–15单元，不污染光影包其他纹理目标。碰撞覆盖向下20格、向上40格，包含少量下方通道和归队需求。

## 性能

同机RTX 4070 Laptop／驱动581.15；131072成员、4个Dome槽、64星柱、100玩家；各模式各运行三次。正常场景按各版本参考轨迹构造同规模跟随输入；压力场景使用同一份字节输入，SHA256为`635356e7d33901874fbbdf12ceb43b6cbbbe736b765dd7054ffa3e51b8959762`。旧版相邻复跑的正常输入也与预存基线逐字节一致。

CPU提交P95约0.18–0.20毫秒。v14驱动缓存缺失的首轮初始化约21.65秒，包含首次编译、测试夹具和资源准备，不能称为单独编译耗时；随后进程初始化约0.81–0.88秒。首次发布合计约37–54毫秒，分帧资源上载泵最大约0.235毫秒。首次成本与稳态必须分开看。

## 重建和复验

开发源位于`scripts/allaystorm/data/dome-v4-source.npz`，是无损压缩数值控制点，不打包入JAR。原始编码及裁剪后资源均已逐字节复现。离线重建只写入build，全部检查通过后仍需生产GPU验收：

```powershell

.\gradlew.bat -I scripts/particles/validation.init.gradle validateDomeGpu validateDome30Hz validateDome60Hz validateDome144Hz validateDome240Hz validateDomeIrregular validateDomeDelayed validateDomeClockWrap validateDomePoseGpu --offline --no-configuration-cache

.\gradlew.bat test check build --offline --no-configuration-cache
```
