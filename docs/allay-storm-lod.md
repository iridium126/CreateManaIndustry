# 悦灵风暴LOD

日期：2026-10-29。状态：✅ 用户已确认LOD2固定世界尺寸版本客户端实机验收通过；阶段7、先前LOD与材质验收保留。当前必需协议22，悦灵和六种剑沿用项目材质。

## 距离、外观与配置

按相机到成员位置的三维距离互斥硬切；LOD0使用实际位置，LOD1／LOD2使用理论归位位置。只排除死亡成员，存活攻击成员仍可在理论位置显示。

| 档位 | 默认距离 | 表现 |
| --- | --- | --- |
| LOD0 | `<120` | 完整悦灵、持剑和动画 |
| LOD1 | `[120,1024)` | 静止简化悦灵，仅头／身体／双臂不透明段，按理论速度朝向 |
| LOD2 | `[1024,4096)` | 每成员一个朝向相机的0.6×0.6格方形，中心上移0.3格，透视自然缩小 |
| 不显示 | `≥4096` | 整实例剔除；这里使用新的默认配置，已有配置不覆盖 |

LOD2固定采样`allay_0.png`左上角起零索引`(7,12)`，RGBA为`(40,179,232,255)`，图集UV为`(7.5/64,12.5/64)`。没有最小像素尺寸，亚像素方形允许不产生片元，成员实例仍保留；使用已有抗锯齿，不新增采样或淡出阶段。

| 配置 | 侧别 | 默认／范围 | 作用 |
| --- | --- | --- | --- |
| `particles.fadeDistance` | 客户端 | 96／16～256 | ALPHA／ADDITIVE淡出起点；MODEL／OPAQUE在该值＋24整实例消失 |
| `particles.stormLod1Distance` | 客户端 | 1024／120～8192 | LOD1结束、LOD2开始 |
| `particles.stormLodDistance` | 客户端 | 4096／0～8192 | 本机LOD上限，0关闭 |
| `allay_storm.stormLodMaxDistance` | 服务端 | 4096／0～8192 | LOD订阅上限，0停止同步 |

实际近界D0=`fadeDistance+24`；远界取服务端／客户端上限较小值，LOD1边界钳制其间，空区间跳过。粒子总开关关闭时取消LOD订阅。MODEL／OPAQUE保留纹理裁剪、披肩／翅膀自身透明度，以粒子中心整实例硬切；ALPHA／ADDITIVE继续淡出，独立阴影列表不受主视角距离影响。

## GPU与显存

实现入口：[StormLodGpu](../src/main/java/com/iridium126/createmanaindustry/client/particles/engine/StormLodGpu.java)、[storm_lod.comp](../src/main/resources/assets/createmanaindustry/shaders/particles/storm_lod.comp)。成员ID索引32字节解析记录，双bank保存记录、两档可见索引及间接命令；不进入64字节通用模拟池、MODEL动画存储、寿命、碰撞、攻击、排序或发射限流。

CPU只提供中心／数量／时间／积分相位。GPU共用`precise`成员种子与`cmiTyphoonHome`计算理论位置；当前帧keygen在视锥剔除前生成近景已覆盖身份位图，LOD过滤死亡与覆盖后生成唯一实例。覆盖数据、候选bank及命令与粒子publication同代提交，不使用旧输入池成员映射。

CPU先以`1.2R+16`包围球检查整个风暴是否落在D0内、远界外或扩展视锥外；通过后才派发成员计算。另投影包围盒8角得到屏幕矩形，目标侧扩2像素，只复制／清理／合成该矩形。GPU逐成员裁剪半径LOD1为0.65格，LOD2为0.75格，覆盖0.3格中心偏移及滚转四角。

| 资源 | 成本与生命周期 |
| --- | --- |
| 成员双bank／位图／命令 | 容量131072，共12,615,760字节，约12.03MiB；无LOD初始只需16KiB覆盖位图 |
| 私有目标 | 每像素`8 + 活动颜色附件字节数之和`：两张depth32F分别保存LOD深度、主场景深度快照，各4字节 |
| 单RGBA8目标 | 1280×720约10.55MiB，1920×1080约23.73MiB；光影MRT按实际格式增加 |

私有纹理按完整视口分配、缓存复用，尺寸／格式变化重建，关闭引擎释放。屏幕裁剪矩形减少像素工作，不缩减已分配显存；成员缓冲与目标显存分别计算。世界尺寸直接使用记录`w=0.3`，没有每帧视口查询或尺寸uniform。

## 光影与远裁剪

两档均通过`CMIPackEntityMergeHook`进入完整悦灵共用的`gbuffers_entities`，保留Iris悦灵身份、原图集UV、全亮lightmap及原生材质／法线／发光编码；无包或原生编译失败时使用引擎独立MODEL／OPAQUE变体。

`StormLodTarget`镜像活动附件格式，使用私有扩展投影及深度，不修改全局远平面、不加载远处区块。合成将主场景与LOD深度反投影到同一视空间比较，保留前景遮挡；先覆盖复制编码颜色附件，再只为主投影可表示的像素回写深度，超远LOD不伪造主远平面表面。

## 独立视觉订阅

`StormLodPreferencePacket`只在登录／显示上限变化时上报。服务端订阅使用双方限额较小值，加入`1.2R+16`外包络和64格退出滞回，不扩大196／260格完整模拟或裂口／云的订阅范围，不授予战斗权限。

| 消息 | 内容 |
| --- | --- |
| INIT | 风暴身份、订阅序号、限额、固定种子／冻结增长定义、已有前后两个规范中心样本、完整死亡集合 |
| UPDATE | 每20tick新中心XYZ／数量／时间、当前tick合并死亡增量；已有完整成员或裂口中心流时复用 |
| REMOVE | 停止／退出／关闭；换维度客户端立即清理，重入发送完整快照 |

共用20tick延迟时间线；不发送逐成员位置、生命值、击退、武器或远景攻击名单。死亡集合选择差分VarInt列表与位图中较小者，完整位图最多16KiB。连接内递增订阅序号拒绝旧INIT／增量复活，断线才重置高水位。无死亡正常远景每秒一个小中心样本，与成员数量无关。

正确性与基准入口统一见[验证说明](allay-storm-validation.md)；已验收尺寸调整的历史性能见[透视尺寸报告](benchmarks/storm-lod-perspective-2026-10-28.md)。
