# 粒子引擎重构状态

本轮普通构建使用原生预编译模块 `12.21.0.0` 和 ABI 12。Storm 模拟默认为 AUTO，主视图 RT 遮挡独立启用。模拟、投影与接收设置见[客户端配置](particle-engine-install.md)。

当前代码中：

- 模拟时钟以世界 tick 为步进单位；暂停时保留上次显示插值位置。显示命令、LOD 覆盖和公共姿态从冻结发布生成，计数采集区分模拟代次、主显示发布及阴影消费的发布。姿态计算直接读取已提交动画库，只发布当前候选所需的记录。
- 显示按已注册布局读取连续字段，帧索引、生命周期和携物标记保持离散。冻结发射器表由同一 GL 命令流共享，只在上传版本变化时复制已初始化的范围。Shared Fate 按实际节点数投影，Partition 在采样拓扑变化时断开前态。物流的主绘制与阴影共用显示时钟采样和照明结果。
- GL 保留 Dome 集结绕障、完成后的回流和历史动态门槛。服务端按确认的有效名单决定是否发动；Dome 在计划开始前仍可同步流暂停。客户端使用同一份 GPU 快照的时间和位图，退出名单由服务端确认。
- 生产接触反馈按攻击和本地目标归约，协议没有代表成员字段。攻击反馈拥有独立的逐 tick 读回队列，通用读回满时不会混合就绪位图。普通路径使用相对运动扫掠，目标传送会断开上一位置；Starfall 柱按实际触地和离地时间裁剪；Dome、Helix 的近距离候选求值解析轨迹并保留端点修正。密集体覆盖证明及完整曲线穿越对照尚未完成。
- 显式 GL 模式由 GL 粒子池持有 Storm 运动状态。RT 模式由持久 CUDA 成员状态直接建立 OptiX 动态实例，与区块碰撞 GAS 共同查询。旧的 GL 模拟后导出 RT 运动快照的路径已退出生产。原生错误槽位使用自己的 CUDA 完成事件保护退休。
- 独立控制通道保存逐 tick 日志，分开记录提交与成功确认的游标。三槽满时保留待发 tick。错误回执保留未确认后缀，继续消费已提交的输入。同一 tick 中互不冲突的成员命令合并提交。同一 tick 已被替换的身份仍随原 tick 确认。GLSL 与 CUDA 共用成员种子、涡旋目标和出生公式。原生步进包含体素身体扫掠和有预算的嵌入恢复，恢复时将前态重置到当前位置。
- 原生 Dome 使用现有逆弧长表进行集结、流暂停和展开。集结及回流共用局部路径搜索。批次按攻击输出成员就绪和退出位图、流暂停以及本地移动目标的接触。曲线接触仍采用采样。原生所有者挂接时，客户端从现有包验收点记录生命周期、攻击、出生、伤害和修正，批次经现有服务端反馈规则处理。
- 原生 Helix 读取已有的刚体参考帧和延迟恢复参数，每攻击每 tick 求值当前和前一参考姿态。成员共用参考姿态，输出就绪位图、参考版本和采样时间，并按退出面或受阻窗口结束推进。Starfall 柱使用原有弧长节点、触地展开和退出规则，接收按列代次、恢复令牌和成员序号标识的快照。恢复期间分步追赶，批次单独输出恢复回执、触地声音和移动目标接触。
- 原生外环从有序输入接收飞行和释放命令，输出带成员身份和外环代次的抵达批次。原生伤害状态保留受击和死亡倒计时，死亡爆散在对应显示发布提交前保留。玩家排斥及权威位置同步直接使用原生 tick 输入。Starfall 柱快照的捕获和恢复共用现有服务端协议。
- 原生显示生产者把活跃成员紧凑写入独立的三个共享输出槽。控制队列在显示槽占满时继续提交原 tick。CUDA 完成和消费之后，显示槽还要等待 GL 使用结束的栅栏才能退休。紧凑记录进入主绘制和阴影共用的模型发布，提供 Dome 阶段姿态与 Starfall 柱曲线的弧长数据。出生和不连续位置断开显示插值。
- RT 渲染自行维护已知不透明地形覆盖，可在无 Storm 的场景运行。碰撞与不透明几何分别发布；包内行号改变不触发未变几何重建。原生遮挡证明直接读取构建 GAS 所用记录；遮挡结果只有在相机、光线及当前包围体仍在证明范围内时有效。阴影还检查遮挡体是否位于当前光源视图内。
- 常规构建配置包含预编译模块及构建期源文件、原生布局清单与 DLL 哈希校验。运行时沿用 LWJGL 实际加载目录，使用可读取的模块版本匹配文件，初始化时校验 ABI 和能力。
- 帧采集增加原生 Storm 分段记录，包含 CPU 提交、CUDA 控制、实例准备、IAS、追踪、模拟、反馈及显示交接、成员范围、地形量和队列深度。CUDA 分段与 GL 及整帧区间可能重叠。

手动修改模拟档位会在 Storm 停止后的身份边界应用。AUTO 遇到故障会从已投影成员切换到 GL 并退休已提交的原生槽。攻击伤害按攻击、玩家及样本 tick 去重，再交由原版受伤规则结算。密集覆盖证明、曲率接触及原生 Dome 受阻的完整玩法对照仍有待验证。

原始三窗和冻结证据仍在 `build/particle-engine/rt-single-step-baseline/`。历史离屏数据只对应冻结版本。RT 投影资格表目前为空，选择 RT 投影时实际沿用 Iris 基础投影。客户端实机验收由用户执行。
