# RT 单次计算计划：实现状态

本次是基础修复候选，**尚未完成整份计划，也不作为 RT 整帧性能收益证明**。默认 `gl`，`auto` 不启用 RT。客户端实机验收由用户执行；当前包仅供工程检查。原有工作区改动保留。

## 已接入生产路径

- 三槽有序提交、完成、消费、栅栏退休；迟到结果不按年龄丢弃，已销毁身份和输入错误也完成消费。环满停止空间快照导出。RT 初始化/执行失败报告状态，只有显式切换才使用 GL 查询。连续切换期间等待旧资源退休。
- 场景身份与地形缓存修订分离。IAS 默认每次重建，按成员范围及实际地形数量整理实例；refit 仅有离屏参考入口。原生消费返回明确错误回执。
- 模拟压缩记录前态槽位。普通存活粒子、金币、羽毛和 Hex 使用该映射，删除显示身份哈希和位移/速度包络猜测。类型声明连续字段；帧、种子、攻击标记及生命周期保持离散。出生、死亡切换和显式恢复传送使用当前状态。
- 金币亮度单独插值。羽毛使用显示池、每显示帧生成的专用可见列表及统一合并纹理单元起点 9。主绘制与阴影读取冻结发布。
- Shared Fate 和 Partition 声明独立的相机相对布局。生产者在模拟输出时维护前态映射，处理身份重用、缺失代次、新增成员和丝带拓扑变化；丝带节点独立插值，节点索引保持离散。两份相机相对状态先转换到显示相机坐标。它们的效果寿命使用世界时间，暂停期间冻结。物流仍使用其生产者已有的双姿态格式，不对其索引或标记执行通用插值。
- Starfall、Dome、Helix 使用共享解析轨迹计算显示时钟处的曲率修正，保留模拟碰撞残差。采集分别记录模拟 census、显示发布、显示源代次和阴影源代次。
- 攻击接触按攻击/目标去重，GPU stamp 从每成员四项缩为 68 个攻击槽，服务端及客户端保留独立去重。伤害配置及原版护甲、盾牌、图腾处理保留。Dome 在计划集结截止 tick 释放，删除 Dome 逐成员集结就绪计算、就绪审核、位图生成/反馈及计数汇总 dispatch；Helix 的旧集结规则暂时保留。Dome 的接触运动和终止状态处理尚在。
- 可见性查询要求同一个可靠 opaque 盒体证明整个模型包围体处于遮挡体的凸阴影体中；中心射线命中仅选择候选。覆盖不足、相机/目标与遮挡体重叠及数值精度不足保持可见。运动代理不是遮挡物。该查询尚未接入在线绘制。

## 尚未完成的核心工作

1. 原生 Storm 状态、解析运动和批次事件的完整所有权迁移。当前 RT 仍提供空间偏好；GL 仍执行 Storm 运动、局部修正、导航和 Dome 接触运动。`gl_queries=0` 只说明 RT 未触发 GL LBVH 回退，**不等于 GL 空间复算总数为零**。
2. 按实际区块内容修订维护独立 GAS；当前仍使用共享盒体 GAS 与实例集合。
3. 删除 Dome 剩余的成员接触/终止审核，并将连续扫掠转移为原生攻击批次事件；当前反馈仍携带代表成员，不能称为完整批次协议。
4. 在线主相机/光源候选与保守可见性保证范围、历史结果处理；可见性整理后的公共姿态/携物变换缓存；移除重复模拟/显示 keygen、全池显示写入和排序。
5. 外部生产者契约已接入 Shared Fate、Partition；物流使用独立的双姿态契约。仍需完整场景覆盖其他外部接入及 LOD、携物、Hex 的全部暂停/恢复与阴影像素差分，不能称为全粒子视觉验收完成。
6. ABI 12 的完整批次事件、显示状态和可见性发布契约。当前 ABI 12 是消费回执/范围整理候选，不能与未来完整契约仅凭版本号混用；安装须匹配包内模块清单。
