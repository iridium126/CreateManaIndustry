# 原生包观察者 GPU 消费组件（2026-10-01）

## 结果与验收边界

本报告记录接入前的 GPU 组件测量；后续实际 hook、成员订阅和 committed admission 接线见[接管报告](package-native-observer-acquisition-2026-10-01.md)。下面的历史组件数字不包含这些新增处理，也不证明完整网络验收。

实现原生相对位置、传送、速度平均和退场的 GPU 处理，并以现有 64 字节 body / 32 字节 history 接入共享发布。每成员一个通用槽位；此域不执行权威物理或库存操作。**实际 Minecraft 原生包 hook、可见接管、权威重复下行抑制仍未接通；总网络带宽与整帧目标没有通过验收。** 不增加任何新网络协议或自动订阅。包解码/GPU 消费不能替代全连接字节计量。

RTX 4070 Laptop GPU，OpenGL 4.5，NVIDIA 581.15，JDK 21.0.8。每次重建独立资源，30 波预热，120 波计时，重复三次。每波所有成员有原生相对位置与朝向记录，使用现有四槽上传，GPU 验证/合并、姿态采样和 mixed buffer copy。GL timer 的同步取结果仅存在于离线 harness；生产组件只用零 timeout 上传槽检查。

新 double 侧缓冲在 131072 容量时额外占 8MiB；该 observer 独立域全部缓冲约 114.5MiB（18MiB 状态、8MiB double、64MiB 四槽完整输入、0.5MiB claims、16MiB 双 body、8MiB 双 history，control 另 16B）。不包含 mixed buffers、模型、通用池、碰撞资源和 Java 直接队列，也不是驱动实际显存峰值测量。紧凑命令虽只上传 64 字节，输入银行仍按最大完整基线 128 字节分配。

## 被拒绝的运算裁剪版本

尝试只在速度变化时读写 double velocity、只在位置变化时检查 double 坐标并部分写回。正确性对照通过，但 131072 三轮 GPU p95 为 2.1012 / 1.6650 / 1.7910ms，原版本为 1.6425 / 1.8893 / 1.5288ms；CPU 提交 p95 同样未稳定改善。未证明收益超过噪声，已恢复原验证版本，不将尝试版作为默认 native 实现。

## 正确性

最终真实 GPU 验证 **4,858,038 项断言**；原有自定义观察者另有 3,547,962 项回归断言。0/1/63/64/65/131072、double 世界边缘、正负半整数及相邻浮点舍入、零轴保留、signed zero、实体 ID/序号、独立 ground/yaw、Create 速度平均、传送、尾部哨兵、有序多包、退休身份不可重引入、整批失败、四槽满超过四帧、重试和全部程序重建均覆盖。离散 double codec 基线逐 bit 对照 Minecraft 实际 `VecDeltaCodec`，速度平均误差要求 <1e-14；呈现 float/yaw 不作 double 精确比较。

JUnit 319 测试、64 suites，0 失败；build 与 Sable 缺席检查通过。GPU 初始 0.15s 平滑/0.2s 预测尚需视觉对照；Create 新生实体的客户端碰撞校正未迁入此组件。此报告不证明网络 ≤ Create，后续必须测入双向权威状态、ACK、初次订阅、控制、所有权迁移及所有保留原生流，并同时确认互动/恢复正确性。
