# GPU 自由包裹环境与空 section：性能验收记录

日期：2026-10-15。GPU：NVIDIA GeForce RTX 4070 Laptop GPU；OpenGL 4.5；驱动 581.15。基线为 `f8337bd21b51c53026107a4005f719bb03e3de41`。基线类与原始着色器由 `prepare_package_baseline.py` 从 HEAD 复制并改名到 build 目录，不改工作区检出状态。

每个场景各运行 5 次对照，交替基线／当前版本顺序；每次测量前预热 5×20 个逻辑步，再取 40 个样本。下表为五轮 p50／p95 的中位数，单位毫秒。CPU 指提交物理步和创建／关闭世界视图的耗时，排除输入重置、GPU timer 等待与读回；不是整帧或服务端 CPU。GPU 使用 GL_TIME_ELAPSED。

## 普通场景

| 场景／数量 | CPU p50 基线→当前 | CPU p95 基线→当前 | CPU p50 变化 | GPU p50 基线→当前 | GPU p95 基线→当前 | GPU p50 变化 |
|---|---:|---:|---:|---:|---:|---:|
| 空气 1024 | 0.1081 → 0.0188 | 0.1786 → 0.0411 | -82.61% | 0.505856 → 0.512000 | 0.523264 → 0.522240 | +1.21% |
| 空气 8192 | 0.1220 → 0.0327 | 0.1650 → 0.0492 | -73.20% | 0.613376 → 0.616448 | 0.619520 → 0.623616 | +0.50% |
| 地面 1024 | 0.1094 → 0.0161 | 0.1381 → 0.0303 | -85.28% | 0.119808 → 0.120832 | 0.124928 → 0.123904 | +0.85% |
| 地面 8192 | 0.1299 → 0.0320 | 0.1660 → 0.0373 | -75.37% | 0.153600 → 0.157696 | 0.175104 → 0.169984 | +2.67% |

四个普通场景均满足中位耗时回退不超过 5%。主要 CPU 改善来自环境程序的 uniform 位置缓存与同一步内绑定去重。两种数量的 dispatch 数分别为 32／34，基线与当前相同；全部普通场景的环境 journal 读回字节为 0。

1024 个包裹采用 32×32 排列，8192 个采用 128×64 排列，间距 1.375 格，空气中心 Y=8，地面中心 Y=1.5。世界 atlas 配置均为 256 个非空 section、1024 个形状；实际覆盖 16／91 个 section，位于同一 Y 层。每个样本重置相同输入，避免长时间自由落体或睡眠替代有效工作。

## 实际缓冲分配和上传

仅独立验收脚本查询 GL 缓冲大小；游戏内不做显存占用统计或展示。`atlas_bytes` 包含几何与四个元数据 bank，仍在 fence 保护中的旧几何缓冲也计入。`total_buffer_bytes` 再包含物理、环境 sidecar 与读回缓冲；不包含驱动私有分配、程序、纹理、其他模组或整个游戏进程显存。整个游戏显存可使用系统工具查看。

| 场景／数量 | atlas 字节 基线→当前 | 已测缓冲总字节 基线→当前 | 几何上传字节 基线→当前 |
|---|---:|---:|---:|
| 空气 1024 | 50,397,184 → 262,160 | 54,386,836 → 4,305,060 | 1,048,576 → 0 |
| 空气 8192 | 50,397,184 → 262,160 | 63,963,284 → 14,254,244 | 5,963,776 → 0 |
| 地面 1024 | 50,397,184 → 1,835,008 | 54,386,836 → 5,877,908 | 1,049,088 → 1,049,088 |
| 地面 8192 | 50,397,184 → 12,845,056 | 63,963,284 → 26,837,140 | 5,966,688 → 5,966,688 |

纯空场景几何数据缓冲为最小 16 字节；其余 262144 字节为覆盖元数据。空 section 无数据槽和几何上传。地面场景上传量没有增加，分配随真实槽需求增长。独立正确性用例还覆盖“非空驻留上限 1 + 512 空 section + 1 非空 section”、历史切换、元数据限额、GPU 读者、扩容／120 帧后收缩及预取。

## 验证状态和原始记录

- 单元测试：612，失败／错误／跳过均为 0。
- 完整真实驱动 GPU 回归：14,679,411 条断言通过；材料专项：475 条断言通过。
- 原版 PackageEntity／NeoForge GameTest：25 项通过；另一个隔离的恢复场景 1 项通过。GameTest 实际依赖 Create 6.0.10，参考源码为 Create 6.0.11。
- 审计清单：148 个来源类；运行时枚举 1703 个 Minecraft／Create 方块、58393 个状态。`--check` 通过；`--acceptance` 仍按预期失败，尚不构成全部语义对齐。

最终汇总和原始样本见 [final.csv](final.csv)、[final-samples.csv](final-samples.csv)。中间测量保留在 pre-binding-optimization、after-binding-optimization、pre-uniform-cache、after-uniform-cache 文件中。pre-uniform-cache 的两种空气场景 CPU 中位回退分别为 +6.68%／+7.30%，因此继续做了缓存优化；报告没有将这些失败记录视为通过。

尚未测量完整特殊环境场景的 CPU／GPU 性能、环境读回、200 tick/s、延迟 ACK 与机器组合矩阵；本报告只判定上述普通场景的性能门槛。完整语义缺口见 [协议与覆盖状态](../../gpu-package-environment-14.md)。
