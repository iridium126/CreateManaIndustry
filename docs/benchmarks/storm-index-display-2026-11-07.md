# Storm 碰撞索引与逐帧显示交接，2026-11-07

原生日志 `Native Storm collision hash exceeds probe budget` 来自客户端碰撞表的无界扩容与原生 65,536 行限制冲突。主表现改为有界构建：最多八次探测，碰撞条目进入有序溢出区，所有查询均检查完整有符号坐标。容量内不因冲突丢失覆盖；原生已知节上限为 32,768、混合占用页上限为 16,384，真正超限返回明确错误。

## 数据与线程

客户端线程在原有时间预算内读取世界，碰撞缓存为每个消费者保留独立增量游标。初次提交完整快照，后续提交新增、变化和撤销；快照中的页引用不随后来缓存修改而变化。打包和 GL 索引构建分别使用专用 Java 工作线程，避免与公共线程池任务争抢队列。原生工作线程按 tick 验证修订链、应用变化、建立索引和空间几何。空增量只推进修订，GPU 占用页只上传实际变化部分；上传槽在对应完成事件后重用，GL 表上传缓冲区按容量增长后复用。

成员模拟和 OptiX 查询继续使用持久 CUDA 状态。CUDA 直接写共享显存输出槽，OpenGL 通过外部内存和信号量读取；D3D12 只提供共享句柄。成员显示位置不经过 CPU。世界输入及服务端所需反馈仍经过 CPU。

完成的显示样本进入有序队列，每个主渲染帧在模拟和显示整理前依次写入 GPU 播放历史。一次完成多个样本时也保留中间历史。显示历史及已显示序号按原生所有者会话隔离，重新挂接时即使成员代次相同、序号从一开始，也不会继承旧会话历史或被误判为过期。模型身份、生命周期和姿态仍通过原有投影发布，主视图与阴影共享冻结显示。插值按样本实际时间戳计算，维持约 100 ms 延迟；暂停冻结，出生、传送和身份切换断开历史，真实缺口使用锚点恢复。没有增加外推或缓冲延迟。

## 原生接口和采集

模块为 `13.0.0.0`、ABI 13。Storm tick 头从 224 字节扩展到 240 字节，末尾追加两个 64 位地形修订字段；基准修订为全一位时表示完整重置。碰撞行携带节坐标及页编号，`-1` 撤销、`-2` AIR、`-3` SOLID，非负值引用本次负载的混合页。工作线程维护稳定的 GPU 页槽并在当步运动前完成修订应用。空间查询包和服务端网络协议保持原布局。

`-storm-input.csv` 记录客户端捕获耗时；`-storm.csv` 增加工作线程索引、几何与上传整理耗时、GPU 上传耗时和地形上传字节数，地形代理数量由完成回执提供。`-storm-display.csv` 记录接收时刻、样本年龄、暂停及缓冲耗尽。JSON 分别统计显示缺号、重复样本、缓冲耗尽和槽不足。重复样本本身不等于运动停止。

## 索引构建对照

相同有序输入，旧构建函数取自修改前源码，新函数调用当前生产 Java 类。独立 Java 21 进程中交错 AB/BA，首轮预热后各五次；所有新索引查询逐项核对。数据为 `build/particle-engine/storm-index-display/index-benchmark/samples.csv`，夹具源码在同目录。

| 规则网格 | 已知节 | 旧索引大小 | 新索引大小 | 旧构建中位数 | 新构建中位数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 32×8×32 | 8,192 | 8 MiB | 256.4 KiB | 17.63 ms | 3.08 ms |
| 40×12×40 | 19,200 | 64 MiB | 1,024.1 KiB | 42.06 ms | 1.81 ms |

这些数值包含各自构建分配成本。JIT、GC 和系统负载未做独立隔离，索引大小也不包含页 atlas 或原生其他资源；它们只验证索引扩容成本的变化，不能换算客户端 FPS 或整帧收益。

## 验证与限制

设备为 RTX 4070 Laptop GPU，OpenGL 4.6，驱动 581.15。现有完整 GPU 回归、Storm 相关单元测试及新增夹具分别记录于 `build/particle-engine/storm-index-display/`。新增夹具覆盖强制哈希溢出、极端有符号坐标、混合页替换、同 tick 撤销、来源重置、陈旧修订拒绝、两类容量边界，以及不执行 GL 模拟 tick 的连续显示接收。

共享输出的验证先在 GPU 内复制到独立缓冲区再读回，避免直接 CPU 读取外部缓冲区时观察到旧缓存；生产显示路径直接使用 GPU 数据。持续夹具使用 65,536 成员、定期页变化及 50/500 ms 注入，核对提交、消费、退休及关闭后占用。首次长时夹具遗漏显示槽准备检查的失败保留在 `soak-15m-attempt1/`，没有记作通过。

全量单元测试共 1,065 项，1,064 项通过；现有 Patchouli 可选条目图标失败：`OptionalDependencyResourceTest.patchouliOptionalEntryUsesAlwaysValidIcon`。其资源在修改前已使用 `trickster:amethyst_knot`，本次没有修改该资源。Python 工具 38 项通过，完整 GPU 回归与专用索引/显示夹具通过。

最终原生持续验证完成 **900.574 秒、65,536 成员、18,000 tick**，提交、消费和退休均为 18,000，117,219 次显示采样；受管原生显存峰值 87,661,488 字节，关闭后为 0。它覆盖的是原生步进、页修订和共享 GPU 历史，不能替代整帧客户端验收。最终清单及产物 SHA-256 位于 `build/particle-engine/storm-index-display/delivery.json`。

尚无本次候选在固定世界、相机和光影下的客户端 A/A、A/B 帧时间对照，也未完成客户端视觉验收。需要重启客户端加载新 DLL，使用 `/cmi particle profile frames 60` 采集相同场景；以帧时间分位数和显示缓冲耗尽记录判断收益。
