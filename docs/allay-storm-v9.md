# AllayStorm 协议9：战斗可靠性、轨迹和专用碰撞

2026-10-18。客户端与服务端核心协议由8升至9，须同步升级。保存格式、HP／死亡、攻击概率、冷却、成员互斥、4个大招槽和64个星柱槽保留。客户端实机由用户执行。

## 战斗与调度

- 显示与点击共用最新完成的GPU拾取快照：保存射线、成员、距离；不以新镜头重算旧接触点，不再要求严格视角匹配或最多4帧延迟。成功消费一次，身份失效仍清理。保留一次客户端遮挡判断。
- `storm_hit` 使用递增VarLong `attackSeq`，替代采样game tick。服务端验证活动维度／epoch、活成员、有限坐标和序号，每玩家每tick一次、滚动20tick最多12次；不积压。移除玩家眼位历史、采样时效、重复距离和服务端方块射线。
- 风暴预测使用双参数本地swing，避免LocalPlayer单参数重载发出原版挥手包提前清空服务端冷却。服务端读取冷却、按武器／附魔／暴击／击退与NeoForge钩子结算后重置并广播挥手。耐久、后置效果、统计、饥饿和成员HP只结算一次。未蓄满仍按原版公式衰减；普通MODEL本地攻击保留。
- Allay代理按玩家／维度延迟复用，攻击前清理生命、药水、火焰、吸收、无敌／受击／死亡计时、速度、下落和目标等临时状态；停止跟踪或换维度释放。
- 调度共享活动、存活、维度、露天资格；露天结果按10tick缓存，不重复逐阶段整片扫描。先抽签和容量／可用人数，再选员和生成几何。
- `/cmi particle allaystorm status` 按需输出大招及星柱的LAUNCHED／DRAW_MISSED／TOO_FEW／RESERVED／CAPACITY／RESOURCE计数，不逐次刷日志。客户端 `/cmi particle stats` 包含碰撞覆盖与预算统计。
- 区域接触的采样秒数保留供诊断，服务端信任GPU实际接触阶段，保留活动攻击身份、成员名单／存活、有限数和玩家／成员／攻击去重。取消历史位置、包络与地形重复检查。伤害仍走原版hurt，保留护甲、盾牌、无敌帧、图腾等防御。

## 攻击变化

### Starfall

集合中心为主体下方8格，四股环绕、每柱64名、64个独立展开方向、落点间距8格保持。下降初始化一次33节点弧长表与节点导数（128段积分、三次反查），之后按三维弧长6格／秒查表推进。集合末段预先衔接下降速度，下降末端切向转入展开。

实际先接地的成员先展开，不等待名义时间或其他成员；展开完同帧收剑回流，跨阶段剩余时间传递。取消固定1.5秒五次缓动，参考面仍为冻结落点的 `h=0.0625r²`、最大r=4、外缘h=1。回流6格／秒连续转向当前移动主体，抵达后恢复普通运动，不用整柱剩余寿命拖慢回流。

允许不平整地面；只定位中心地面，不扫整片平整度、不周期重查、不在接触时再扫。MODEL裁剪、滑动、脱嵌仍决定实际位置，可以偏离参考面或降低实际速度，不暂停阶段进度等待恢复参考面。未知碰撞继续视觉运动；未实际确认接地者不能出剑伤人，可无伤害回流。

粒子内标记改为归一化展开进度，原生MODEL、阴影、Iris、接触统一读取。128粒子半尺寸预警圈仍显示；不足128粒子不再拒绝伤害。触地声每客户端每tick最多2个。

### Helix

保留原选员份额、上限、至少512名与相对风暴臂各至少256名门槛。直接集结于玩家水平后方24格、上方24格附近；前端朝斜下45°指向玩家，尾部向后延伸。集结中每10tick更新，客户端连续插值；集合结束用最新目标冻结轴线并立即突刺，移除主体集合后接近、3–8秒蓄力和1.5秒等待。

长度32–64格、半径3–6格。围绕两条螺线的局部法平面两轴生成高斯偏移，σ=0.2R、径向截断3σ；由种子和稳定成员身份生成一次缓存，不逐帧采样。成员不会全部贴在数学螺线上。几何校验、45°斜率、观察／碰撞范围和GPU读取同步扩大；保留原突刺速度配置。

### Dome

保留最低768名、原配置份额与上限、六瓣、顶冠与瓣间空隙。只在启动时定位一次中心地面；不检查整圆同高露天覆盖、不扫描全部出口、不因目标跨1格高度或动态障碍中止整波。局部运动交由客户端碰撞。与Starfall圆环完整性、Helix全局碰撞就绪位无依赖。

## 独立风暴碰撞域

普通MODEL／其他粒子继续使用原通用8槽；主体、三类攻击与尸体查询新域。只保留整格占用语义，不引入自由包裹的摩擦、环境与移动结构解算。

| 位图 | 每段128个uint＝512字节；AIR／SOLID共享标记 |
| GPU | R32UI整数3D图集；RGBA32I TBO哈希页表，最多8探测，冲突则扩表 |
| 初始容量 | 4096个活动混合段＋替换保留，总8192物理页＝4MiB；页表另计 |

| 覆盖 | 完整主体外缘／高度带、所有柱、完整放大螺旋、全部Dome、回流和成员探测余量的区块段包络；重叠只存一次 |
| 需求变化 | 段化边界不变不重建；边界变化保留交集缓存，只采集新增／失效段；退役范围额外保留20tick覆盖尸体；近处优先但保留远处全部需求 |
| 采集 | 所属客户端线程，默认1ms软预算，32格批次可续跑；只读已加载数据 |
| 上传 | 默认0.5ms软预算、每帧最多128KiB；地形和需求稳定时零上传且跳过全页回收遍历 |

| 未知 | 未加载／采集未完成／设备失败明确UNKNOWN，不主动加载区块，不作为已覆盖空气，不静默退回通用8槽 |
| 更新 | 方块、区块加载／卸载、ALLVR立方体通知；受影响段与必要邻接段增量更新，取消每秒全量烘焙 |

`PackageCollisionRuntime.peekSnapshot` 只读取已经存在的当前不可变CPU快照。可直接转占用位图，遇unsupported形状则走轻量读取；不为风暴请求包裹完整形状采集或初始化包裹GPU域。没有快照时，空段使用已加载区块段的正面证明，其余逐格读碰撞形状是否为空。后台不读取世界。

诊断包含requested／covered／unknown／pending、采集耗时／超预算次数、需求生成耗时、GPU已发布段数、物理页／字节、累计上载字节、上载耗时／超预算次数和资源异常。软预算不能抢占单次Minecraft／驱动调用，发生超时如实计数。

攻击参数＋状态双bank为8,037,760字节（协议8为3,843,456）；新增下降弧长和高斯缓存。碰撞图集按活动段及替换版本独立增长，不能把位图净2MiB误写为总显存。

## 性能证据与实机交接

设备：RTX 4070 Laptop，NVIDIA 581.15。`build/benchmarks/storm-v9-final/` 保存原始CSV。64柱固定输入update，三轮各40次预热＋120样本：最终轨迹版本P95为0.048128／0.047104／0.047104ms；早先协议9记录为0.030720ms，协议8历史记录为0.023552ms。新增弧长／回流状态有GPU成本；本次也观察到主机负载与频率波动（同期查询GPU为1125MHz、45%利用率），未控制外部负载／时钟，不将这些跨轮差值精确归因于代码，也不宣称整体性能提高。

CPU提交P95为0.0063／0.0051／0.0016ms。初始化阶段单独测量，`starfall-arc-initialization.csv` 最终约0.279ms P95（此前约0.181ms）；该阶段内核已预热，不含着色器编译或真实游戏冷启动。无碰撞下降速度在各帧率测得约5.999–6.000m/s。

专用域压力场景20,000段／9,000混合页，活动覆盖没有容量淘汰，初次分批上载191次，记录图集＋表约16MiB、累计主机上载约20.4MiB（包含分阶段页表发布）。稳态上载为0，单独CSV记录24,097次页查询GPU P95约0.008–0.009ms、pump CPU P95约0.0007–0.0011ms。这里不包含Minecraft世界采集成本；128KiB是单帧字节上限，不能将放宽时间预算的验证泵次数当作实际游戏冷启动帧数。

服务端强制选择的冷调用样本：16384成员Dome规划约15.8–103.2ms、Helix见日志各轮样本（含JIT、首次类加载、测试环境和主机负载差异）；不是稳态分布，也没有同场景旧版服务端基线，不据此宣称tick改善。代码减少的路径包括玩家历史、接触复查、整片几何复查、失败选员扫描和代理反复创建。真实客户端CPU／GPU帧耗时、世界采集冷启动与稳态、完整最大主体＋64柱＋4大招的复杂已加载地形，以及多人帧率的前后对照尚未实测，交由用户完成；固定输入微基准不等于游戏帧率。

用户重点验收：

- 快速转头／移动点击／不同GPU回读延迟、两名玩家各自攻击，观察冷却、未蓄满衰减、命中反馈和耐久。
- 星柱全程流动，先落地先展开、逐成员独立抛物面、展开立即回流；坡地、台阶、墙体、动态编辑、碰撞未知后无伤害回流。
- Helix直接在玩家附近集结、移动跟随、结束即45°突刺，截面高斯疏密稳定，无全部吸附螺线；Dome正常触发并保留空隙。
- 最大主体＋64柱＋4大招，检查状态中已加载活动需求最终全部覆盖，未加载段明确未知；同时启用自由包裹，编辑、卸载、跨段、ALLVR高度和重载。
- 无光影及实际Iris／Sable、近远景规模和多人帧率，记录世界、人数、设置及冷启动／稳态采样，不能用离屏结果代替。

保留信任边界：GPU客户端提供成员拾取、运动、实际触地与接触候选；服务端拥有成员生命、武器与最终伤害结算，不新增服务端成员位置模拟。
