YSM resource compatibility implementation

The internal algorithms, raw resource model and binary resource parser are
adapted from OpenYSM, copyright (c) 2026 OpenYSM, under the MIT License.
See ysm-OpenYSM-MIT.txt. Changes include package relocation, removing native
dependencies, retaining only file decoding, bounded input and decompression,
strict primitive/string readers, and removing diagnostic model-data output.

The internal zstd package is the pure Java decoder distributed by OpenYSM.
Files carrying Apache License 2.0 headers retain those headers. The Apache
License text is included in ysm-zstd-APACHE-2.0.txt. The package was relocated;
only dependencies of the streaming decoder are included.

The independently implemented cuboid reconstruction uses the geometry and
coordinate-system observations in YSM-Report and YSMParser. It validates
reconstructed positions, normals and per-vertex UVs and rejects unsupported
geometry rather than dropping cubes.

No proprietary YSM binaries or user model samples are included.
